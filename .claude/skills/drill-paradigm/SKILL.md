# 题末范式：做完一题，写一份能抄进 A4 的照做清单

**核心观念**：范式是考场 A4 速查纸的原稿，不是讲解。读者看一眼，就能照着做出同一类题。"为什么"留给题目正文和 QA；范式里只写"怎么做"。

**触发**：练习题逐题拆解（`output/{课程}/drill/`）里，用户说"第 N 题做完了，总结"。

**流程**（每一步都有产物，验收在步骤里）：

## 1. 找题型 → 产物：本题的题型清单

- **按题型分块，不按小问号**。块标题写"给什么，做什么"，例如"给文字描述，画有向图 + 条件分布表"。标题里不写 (a)(b)。
  - 一个小问里有两种动作，就拆成两块。
  - 几个小问是同一个动作，就合成一块。
- **材料来自三处**：
  - 官方解答的做法；
  - 每个小问「思路」里的捷径和判别（例如"两点间有直接边，不用查"）；
  - 本题 QA 里用户卡住过的点。
- **验收**：题里每个小问都落在某一块里。用户跳过不看的小问（例如证明题）也要算进去。

## 2. 每块写步骤 → 产物：几行编号步骤

- 每步一短行，用动词开头，照着就能做。
- 删掉三类东西：解释为什么的句子、自检步骤、过渡句。
- 最关键的"为什么"可以留一行，以 `直觉：` 开头，单独成段。
- **用户不会的操作，要拆到能照做为止，不能一句带过**。判断方法：一步里如果藏着"怎么做"的子动作，就把它拆开。
- 并列的规则清单（几条规则平行列出、彼此不分先后）用三列表格：`| 规则 | 式子 | 直觉 |`。步骤类内容不用表格。
- **验收**：步骤文字大约半页；例子按需要写长，不为省篇幅删中间步骤。

## 3. 造例子 → 产物：块首写全例题条件 + 每步一个 `例：`（这一步的完整算式）

- **不抄题，而且全部用同一张例图 G**：课程的总收录 `drill/exercise_cheat.md` 开头画着例图 G，所有范式的例子都尽量在 G 上做，块首写"例图 G"，并把图嵌进来（`![](../cheat_figs/G.png)`）。考场上只看得见 cheat 里那一张图，所以不能写"上面的道德图"这类指代，只能写"G 的道德图"。只有 G 实在表达不了、或者和别的范式冲突时，才加第二张图（同样画进 cheat 开头）。简单概念（比如观测 / 隐变量、链式法则）不需要图。
- 这一个例子要贯穿全块每一步，并覆盖每种情况。比如 d-分离的例子要同时含链、分叉、汇合和后代。
- **例子就是一道做完的例题，考场上要能直接照抄成解题过程**。左边的步骤是文字，右边的 `例：` 必须是这一步当场写在卷子上的完整算式：
  - 先写出完整的式子（联合分布、要求的量、提出求和号后的式子），不要写"上式""同上""这一边加掉"这类要读者自己翻译成过程的话；
  - 中间步骤不能省（考试写过程，缺一步就扣分）。代入数字时，每一格都写出"公式 = 数字代入 = 结果"，不为省空间只展开一格：速查纸是拿空间换脑子；
  - 讲步骤用的求和式（消息、边缘、联合），不必把所有组合都列出：挑一个代表写全。先写带全部乘数的完整公式，例如 \(\mu_{f \to A}(a) = \sum_b \sum_c f(a,b,c) \cdot \nu_{B \to f}(b) \cdot \nu_{C \to f}(c)\)，不能只写"因子 × 其他消息"；再挑一格，把每个乘数按求和变量的取值顺序列成向量，逐项相乘再加，例如 \(a{=}0\)：\(bc = 00, 01, 10, 11\) → \(f = (0.36, 0.04, 0.05, 0.05)\)，\(\nu_B = (1, 1, 1, 1)\)，\(\nu_C = (1, 1, 1, 1)\) → \(0.5\)（全 1 的乘数也照列）；其余格写"同样得 …"。上一条"每一格都写"管的是题目要的那张答案表本身；
  - 一个 `例：` 写不下就用 `<br>` 分行，仍放在同一个灰框里。
- **块首写全例题条件**：用哪张图（图 G，或块首用一行写出的小图，如"链 A – B – C"）、每个变量取什么值、给了哪些表或参数、求什么。每块都要自带条件，不能写"同一条链""数据同上一块"，因为抄进总收录后上下文会变。唯一例外是例图 G 本身：它画在总收录开头。
- **验收**：每个 `例：` 的结果都手算核对过；把所有 `例：` 按顺序连起来读，就是一份完整的解题过程。

## 4. 写入、编译 → 产物：题目 PDF 末尾的范式面板

- 位置：题目 md 里，`## 易错点` 之后、`## QA` 之前，标题写 `## 范式（做完这题的总结）`。
- 块标题用 `**粗体**`。不能用 `###` 或 `####`：编译器会把它们当成小问，套上小问面板。
- 用 `.claude/skills/tutor/scripts/compile_drill_pdf.py <md>` 编译。编译器的处理：
  - `## 范式` 套进棕色面板；
  - `例：…` 变成灰框，另起一行，和步骤分开；
  - `直觉：…` 变成绿色行。
- 抽看渲染页：例子和步骤分开显示，公式没有冲出格子。

## 5. 抄送总收录 → 产物：`drill/exercise_cheat.md` 更新

题末范式写完，同一份内容也抄进 `exercise_cheat.md`。那份文件按关键字组织，考场上靠扫标题检索，不靠记题号。

- 每个原子操作一个 `### 关键字（讲次）　题型` 标题，例如 `### 道德化（L3）　给有向图，画道德图`、`### 重构图 / UNDIRECTEDGRAPHELIMINATE / 消元团（L4）　给无向图 + 消元顺序`。关键字要用考场上会去找的词，课件里的算法名也要放进标题。
- 已经有的关键字不重写，只在文末「## 覆盖」里补一行；只有新操作才加新标题。别的块要用到已有操作时，写一句"先 X（见「X」）"，不重复讲。
- 内容原样搬过来，不改写、不拆块、不改名。组织靠标题，不靠改内容。
- 新块和已有的某块其实是同一件事（例如"变量消元 VE"和"数值求概率表"）：两块合成一个更好的版本，保留两边调好的步骤，标题里并列两边的关键字（`### 数值求概率表 / 变量消元 VE / ELIMINATE / …`），保证查哪个词都能找到这一块。
- 改完跑 `.claude/skills/tutor/scripts/check_cheat.py <drill_dir>`，然后编译 PDF。

## 对照样例（举例：一道"有向图 → 无向图"的题）

**太啰嗦**（这是讲解，不是 A4 原稿）
- ✗ 6 步，每步带一句原因；另外还有自检步，以及"势函数不唯一，乘任意常数 Z 跟着变"这类直觉行。
- ✓ 每步一短行加一行例子。只留一行直觉，说明父节点为什么要连。

**用户不会的操作一句带过**
- ✗ `道德化：同一孩子的父母连边，去箭头。`
- ✓ 拆成两步，各带一行例子：
  - `道德化①：每个节点的父节点两两连边，只有一个父节点的不用连。例：C 的父 A、B → 加 A–B；D 只有父 C → 不加`
  - `道德化②：箭头全部去掉，变无向边。例：A–B、A–C、B–C、C–D`

**按题号组织**
- ✗ 块标题 `(a)(b) 有向图 → 无向图 + 势函数`
- ✓ 拆成两种题型：`给文字描述，画有向图 + 条件分布表`、`有向图 → 无向图，写势函数`

**抄题**
- ✗ 例子还用原题里的变量和设定
- ✓ `例图 G`（A→C←B，B→D，C→D，C→E）：C 的两个父节点没连，要补边；D 的两个父节点已经连着，不用补；E 只有一个父节点；D、E 是兄弟。几种情况都在这一张图里，d-分离、消元也都能用它。

**指代考场上看不见的东西**
- ✗ `例：上面的道德图`
- ✓ `例：G 的道德图`（cheat 开头画着）

**例子只写结论，读者要自己翻译成过程**
- ✗ `例：每一边把自己的变量加掉……右边 Σ_C e^{BC}：B 取哪个值都是 e + e^{−1}`（没写联合式，没写"加掉"是哪条式子，没写每格怎么代）
- ✓ 先写 `p(B | A=+1) ∝ Σ_C ψ(+1, B) ψ(B, C) = ψ(+1, B) · Σ_C ψ(B, C)`，再逐格写 `m_C(+1) = ψ(+1, +1) + ψ(+1, −1) = e^{1} + e^{−1}`，最后写相乘和归一化的每一格
