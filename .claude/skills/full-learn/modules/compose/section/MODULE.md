# compose/section — 节层

## 职责
把一个（或一小组）节点写成一条读者能跟住的推理链：从入口问题出发，经过尝试与障碍，到洞见与结论；结论从画面里推出来，而不是从定义里抄出来。

## 继承 / 覆写
继承 core、compose。

## 变体
- `variants/prereq.md` — 前置节（external prerequisite）：快餐写法，覆盖表点名被覆盖的条目，其余继承本模块。

## 输入
spine.md 中本节的四格 · tree.json 中对应节点 · raw/ 中对应页

## 输出
一节正文（T4 节格式）

## 公开方法
1. `prepare` — 动笔前想清楚（这节只装一个念头是什么、读者现在手里有什么）
2. `reason` — 写推理链
3. `land` — 落地：例子 / 数字 / 运行案例
4. `seal` — 节末：结论、和大图的连接、留下的问题

## 调用
devices（类比、例子、图、公式、块）
