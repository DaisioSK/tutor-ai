# section 变体 · 前置节（external prerequisite）

## 一句话

前置节是快餐：**独立、直接、精简、通俗**。开头一句结构念头，从浅到深走几级台阶，每级标出"到这里够用了"，读者能懂到哪就停在哪；只读这一节、不看书里任何别处，也不会被绕晕。**引用只能单向：后文引用前置，前置绝不提后文。**

## 适用对象

节注释 `nodes` 里全是 `kind=external, role=prerequisite` 的节。spine 已把它们扎成前置包（卷首「补给站」章，或章首小堆）。混有材料节点的节不是前置节，走 common。

## 为什么要变体

common 的节范式是为材料节设计的：钩子从运行案例的痛点开场、节末连到下游、留下的新问题接下一节、例子优先用运行案例。这些规则作用到前置节上，每一条都把后文拖进来——读者在一堆还没学的符号（λ、μ、ρ、P_j(t)）中间学新数学，每个符号都只能先记着。前置的价值是一把干净的工具，所以前置节要的是一个念头加几级台阶，不是一条从痛点出发的推理链。

## 继承规则

下表之外的一切按 common 走：先日常语言后形式化、不用术语解释术语、公式先思路后式子、符号给读音、🗺️ 路线、📌 一句精确定义、✅ 目标行、禁止清单、保真。common 以后新增或修改的规则自动作用到前置节；只有下表点名的条目被覆盖。

## 前置节长这样

```
## §N.M 中文 (English)
<!-- nodes: N-xxx | sources: — -->
> 📍 **前置** · 约 N 分钟 · 够用线：<读者会做什么就可以回主线>
> 🔑 **一句念头** <tree 的 mental_model，一两句>
> 🗺️ 念头 → 台阶 1 … → 台阶 k → 例子
（台阶 1：最浅的一层，从念头直接推出；末尾「够用线 ①：…」）
（台阶 2…k：每级在上一级上加一层，规则都从念头推出，不单列孤立规则；最多 4 级）
（一个纯数学例子：只用数和本节自己的符号）
> 📌 …
> ✅ 这节拿到了：…
```

- **🔑 一句念头**就是全节。写完回头检查：删掉台阶，只留念头，读者能不能自己推出第一级？推不出说明念头还不是结构，是口号。
- **台阶由浅入深**：台阶 1 是"会用"，后面是"知道为什么"。每级末尾的「够用线」告诉读者：后文只要用到这里就可以停。够用线的深度由后端的使用者决定（反查 `requires` 得到用它的节点、读这些节点用到它的哪几条性质），但正文只写"会做什么"，不写"第几章要用"。
- **成对概念同节**：tree 里标了 `pair` 的两个前置在同一节，念头一句话讲清两者的关系（"导数剥掉一层累积，积分加上一层"），台阶交替推进两边。
- **篇幅**：正文最多约 40 行、约 5 分钟。最多一个比方、一个例子。
- **例子**：纯数学的数（0.25、e⁻¹、从 2 到 3 的面积），不用运行案例、不用课件例题、不用材料的符号。
- **不许出现**：后文节号与章号；比本节晚出场的材料节点的名称与符号；运行案例；指向材料页的脚注；"老师直接写……默认你会""第 N 章会用到"这类预告。往前引用（更早的前置）可以。
