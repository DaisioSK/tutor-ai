# compose/chapter — 验收

本表只列人要做的条目（self / cold-read / 脚本未实现）；纯脚本检查在同目录 `GATES.md`，写作时不必读。

检验对象：`book/NN-<slug>.md` 的章级结构，以及写作期的编排表（每节分量档 / 负载档，作者底稿，不进正文）。脚本检查在 `verify_book.py`，检查名以 audit PARADIGM「脚本注册表」为准。

| id | 验收标准（可判定的一句话） | 检验方式 | 不过时回到 |
|---|---|---|---|
| E-CHAP-05 | 能力闭合：逐行对照 spine.md 本章表的"解锁了什么"列，各节解锁之和恰好构成本章能力；把全书各章能力并起来能推出 tree.json 的 apex | self: 列出本章各节"解锁"，逐条勾到章能力的组成部分，有剩余或缺口即 FAIL | PARADIGM 理论 1 |
| E-CHAP-06 | 反向闭合：每一节要么服务带走清单的某条，要么被后面某节的"凭什么现在能懂"引用；两者都不满足的节已压成背景档 | self: 逐节查它是否出现在带走清单的落点或 spine 后续行的依赖列中 | PARADIGM §方法 2 |
| E-CHAP-08 | 编排表里每节都标了分量档（核心 / 常规 / 背景），档位以 tree.json 该节点 weight 为起点；标核心的节集合 = 带走清单 N 条的落点集合（及其直接推导） | self: 打开编排表，逐节对照 tree weight 与带走清单落点，不一致处写出理由或改档 | PARADIGM §方法 2 |
| E-CHAP-10 | 章内篇幅次序为 推理/认知 > 做法 > 操作细节 | self: 把每节段落粗标三类并累计字数，次序不对即 FAIL | PARADIGM §方法 2 |
| E-CHAP-11 | 权重修正是再分配：修正后整章字数不增加，增加的字来自重复段与背景节，长错的节被砍短而不是重点被加长；单节超出 section 参考区间的已拆节或精简，灌水已删 | self: 记录修正前后各档字数，对比总字数与背景/核心增减方向；列出越界节及处理 | PARADIGM §方法 2、判断准则 |
| E-CHAP-12 | 负载评级只存在于编排表，按定义诚实打分（轻 = 术语/分类/定义、无推导；中 = 一机制一例子、公式不推导；重 = 推导链/公式表/多步算例/多概念对比；含推导链的节判轻即 FAIL）；正文不印负载评级；节级 🧭 全书统一开或关（默认关），开时只含分量/时长/读法 | self: 对照三档定义逐节复核评级；grep 正文无"轻度/中度/重度"负载标签 | PARADIGM §方法 2 |
| E-CHAP-17 | 连续两个轻节中至少一个有画面（正文一句带画面的话或一个 📎），不靠硬配 💡；轻节不为凑数配类比 | cold-read | PARADIGM §方法 2 |
| E-CHAP-18 | 每节以一句过渡收尾，该句对应 spine 本节"留下的新问题"，且正是下一节的入口问题；下一节不做"前情回顾" | self: 把每节末句与 spine 对应行、下一节首段并排对读 | PARADIGM §方法 3、理论 4 |
| E-CHAP-20 | 首章开章从零开始；非首章开章前 2-3 句接住上一章收章抛出的问题，本章依赖的上一章节点在这里自然带过 | cold-read | PARADIGM §方法 1 |
| E-CHAP-21 | 冷读者读完开章能复述：本章要解决的具体问题（用人话）、它为什么值得在乎；问题本身在任何解法出场前已被讲清 | cold-read | PARADIGM §方法 1 |
| E-CHAP-22 | 收章：回到开章问题并作答；复述本章念头 + 「你现在能做到」（对应章能力）；回到骨架——开章骨架段的每个大概念在收章再次出现，并带上本章得到的具体结论（式子/数/条件） | script: verify_book.py#close + cold-read | PARADIGM §方法 4 |
| E-CHAP-24 | 收章最后抛出下一章入口问题，与 spine.md 下一章"章入口问题"一致；正文不手写上一章/下一章链接 | self: 与 spine 下一章入口问题逐字对照 | PARADIGM §方法 4 |
| E-CHAP-26 | 不存在"卡住了怎么办""验算清单""练习题"之类综合章 / 综合节；提示与例题出现在它所属知识点的那一节 | script: verify_book.py#no_catchall + self: 逐条提示查其所属节点 | PARADIGM §方法 3 |
| E-CHAP-27 | 节标题按内容命名（说讲什么），不出现技法名（对照式、痛点-方案-效果、发散 等）；正文无"① 契约"式编号小标题 | cold-read + script: verify_book.py#numbered_slots | PARADIGM §方法 3 |
| E-CHAP-29 | 冷读者顺读全章不报告"连续读不动"或"在读名词表 / 被浪费时间"类节奏问题 | cold-read | PARADIGM 理论 3 |
