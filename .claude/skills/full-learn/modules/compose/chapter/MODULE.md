# compose/chapter — 章层

## 职责
一章 = 解锁一项能力。负责开章（把章入口问题变成读者自己的困惑）、节与节之间的节奏与过渡、收章（回扣入口问题、抛出下一章的问题）。

## 继承 / 覆写
继承 core、compose。

## 输入
spine.md 中本章的段落

## 输出
`book/NN-<slug>.md` 的章级结构（开章、节序、过渡、收章）

## 公开方法
1. `open` — 开章
2. `pace` — 节奏编排（轻重交替、何处换气）
3. `bridge` — 节间过渡（上一节留下的问题 = 下一节的入口）
4. `close` — 收章
