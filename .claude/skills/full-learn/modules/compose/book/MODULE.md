# compose/book — 全书层

## 职责
让整本书是"一本书"而不是章的堆叠：书首交代终极理解与读法、运行案例在全书里的起伏、书尾的收束、跨章引用一致。

## 继承 / 覆写
继承 core、compose。

## 输入
T3 `spine.md` · T2 `tree.json`

## 输出
`book/00-front.md` · `book/99-back.md` · 全书跨章引用

## 公开方法
1. `front` — 书首：终极理解、科技树图、怎么读
2. `thread` — 运行案例在各章的出场计划
3. `back` — 书尾：回到终极理解，把全书收成一张图
4. `xref` — 统一跨章引用格式
