# compose/devices — 表达器件（工具类）

## 职责
提供 section/chapter 调用的表达器件，每种器件定义"什么时候用、怎么用、什么时候不用"。器件服务推理链，不是装饰。

## 继承 / 覆写
继承 core、compose。

## 公开器件
- **类比** — 画面与日常类比
- **例子** — 入门例、课件例、运行案例、数字算例
- **图** — 课件原图 / 自绘图 / ASCII 图
- **公式记法** — 公式的写法与推导排版
- **块类型** — 视觉签名词汇表（陷阱、外部补充、换气等）
- **出处** — 脚注格式与"不描述课件"
- **表格** — 何时用表、宽度限制

## 扩展点
加器件 = 在 PARADIGM 加一节"何时用 / 怎么用 / 何时不用"，EXPECT 加对应验收。
