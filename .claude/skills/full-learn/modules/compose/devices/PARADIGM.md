# compose/devices — 范式

## 一句话

器件是推理链上的台阶与路牌：每个类比、例子、图、公式、表格替推理承担一步，每个块标记诚实地告诉读者这块该带什么状态读。不承担一步的器件是装饰，标记说谎的块比没有块更糟。

## 理论

**1. 器件对应卡点。** 一节是一条推理链（section 负责）。读者卡住无非几种：没有画面、没有实例（不知道长什么样、代什么数）、看不见结构、读不懂记号、分不清邻居。器件一一对应：类比给已有经验一个解码入口，例子把式子变成能代的数，图摊开结构，记法让符号可读，比较与决策树分开邻居。所以器件由卡点召唤，不由"每节配齐"召唤；器件之后必须有一句话用它推进推理。

**2. 另一半职责是预期管理。** 硬核推导、缓气画面、回查定义长得一样，读者只能用同一专注度读全文——沉闷、课件感。块类型让每块视觉上自报性质：多专注、能不能跳、何时回来翻。导读条对整节做同样的事；它管预期，入口问题管好奇，两者不冲突。

**3. 诚实：块是加法，不是替换。** "可跳"成立的前提是：材料的每样内容——定义、公式、表格数值、老师的例子、强调的边界——已在正课或校准块里完整出现（老师的例子也可落在 🔍 的真实场景段，它讲的是真事），附加块只叠在上面。检验：删掉所有附加块，书仍完整覆盖材料。把正课包进辅助块、硬配块，都是让签名撒谎；读者被骗一次就不再信标记。

**4. 内外可分，不编造。** 材料内走正课并用脚注指回原页；材料外按粒度标记（行内、整块、整节）；编造的边界归 core。

**5. 重讲，不复印。** 材料是证据与出处，不是被描述的对象。"幻灯片上红框框了"描述的是载体，读者读完仍不懂。要原话就摆原文再解读，要图就嵌图再讲图上没写的，要指回就用脚注。

## 方法：器件逐个

### A. 原文 → 我读到的

- **何时用**：讲到材料里任何具体东西——定义、题、表、代码、数据结构。读者的瓶颈不是读不到原文，是读到了没有解读。
- **怎么用**：先摆原文（英文原句 blockquote 原样、表抄成 Markdown 表、代码进代码块），紧跟一段第一人称"我读到这里想到的是……"，像高手站在旁边边读边说；成对出现才算一次解读被接收。读表逐行逐格示范（"这一行 1, 0, 0.6 读作：X₀ 取 1 时 X₄ 取 0 的概率是 60%"）。讲结构给一个具体对象的完整实例（构造 + 摊开的行），讲操作给"输入 → 输出"，小结构逐节点逐边列出；字段清单不算展示。能运行的东西真跑一遍，用跑出的实例。不说"自己去看原数据"。
- **何时不用**：纯包装性原话不必照录。连续的原文-解读链里不插 🔍/📌/📏/📎 卡片——会把解读切成卡片集；定义直接写在行文里。

### B. 类比与画面

- **何时用**：定义读完仍"只是符号"时——类比让已有知识参与解码，否则只能靠陌生符号硬建模。核心节点默认需要一个画面，难消化处鼓励多用。
- **怎么用**：定义在前，随后一段辅助让它有画面：类比、数据流画面、简图，或"说人话就是……"。选类比只认同构——关系一一对应（图书馆找书对应 Q/K/V 三角色），同构比贴近生活重要；灵感可取自餐饮、出行、团队、游戏、自然等。要轻：1-3 句给个画面就退出，不长于定义段；1-2 句留正文，≥3 行装进 💡。结尾一句"对应到 X 世界：……"钉回术语。类比要承担推理：后文能借画面推出东西（浴缸水位稳住 → 水量 = 进水速度 × 停留时间 → Little's Law 不问分布）。
- **何时不用**：简单原子概念跳过；背景节不硬配。不同构宁可不要——错类比比没类比更坏。辅助里不引入新术语或产品。类比是给身份证配照片，不是换身份证：不能先行代替定义；十个概念十个"图书馆"，读者抓不住重点。

### C. 例子

例子告诉读者"长什么样、代什么数"，公式表只说"有这条式子"。形态按节点 kind：formula/method（核心计算点与抽象）挂一个走完全程的数字算例；concept 挂一个最能说明问题的关键例子；fact 几行带过。

- **选例**：覆盖最大化、复杂度最小化——一个（复杂时 2-3 个）不复杂但演示定义所有组件、角色所有特性的 case。来源：能用全书运行案例就用；否则材料自带的例子与练习（读者回看认得出，两遍强化），往年题/练习原题连数字一起优先于讲义例的简化；都不合适才自编，从材料例改造。材料例是素材不是成品：口语重写，归进合适槽位再丰富。
- **数字算例 · 规模**：能心算或一步按计算器；数据 ≤5 条、单字符 key（"the cat" → a / b）、维度小（4-token 不是 1024-token）。复杂数据让读者分心解码数据——这一步教流程不教数据。
- **数字算例 · 选数**：数是用来让方法现形的，不是让某个结论恰好成立的。挑完数先问"换一组数，这套算法还走得通吗"——走不通（例如只有 mμ−λ 恰等于 μ 时某个材料外捷径才成立），说明读者学到的是巧合，换数或换路。同一章的几个例子把参数拉开（ρ 取 0.5 与 0.9），非线性才看得见；几个例子挤在同一档，读者只会以为结果"差不多都这样"。
- **数字算例 · 串链**：算出 A 顺手算 B、C；一个例子跑十个公式，胜过十个例子各跑一个（后者看不出公式间关系）。同一组数上做 what-if（换快机器、负载加倍、改 m 台），并列结果让因果浮出来。
- **数字算例 · 结构**：① 一句话思路（≤3 句，写给没做过的人：验证什么 + 怎么下手 + 关键一步），没有它换个数字就不会；② 已知量翻译：题面逐个翻成符号，每个变量配中文意义（不写"λ = 5/hr"，写"到达率：每小时来 5 个"），单位换算写在值里，点明是间隔还是速率、单台还是整机；③ 逐步求解：每步一行写"求什么"，公式与代入分列，中间步骤全留不合并，界/公式类先化简再写各取值，算法类走完所有步骤；④ 一句结论回答入口问题。步骤与官方解法同构，数字对齐官方 solution，对不上或舍入不同就并列两个数并说明来源。
- **引用材料例题**：原文照录（英文原句，不复述不缩写，读者靠字面认出）→ 已知量翻译 → 求解，三块齐全；自编算例可省原文块。压缩题面时应用背景句与角色定义句一字不删：前者是符号接回现实的唯一桥（丢了"终端系统"那句，题就成了抽象数学题），后者点破与惯例冲突的符号（λ 在这里是服务率不是到达率）；可删的是故事包装、重复背景数据、无关机构名。练习原题标出处脚注（如 Tutorial 2 Q2）。
- **真题例**：范围内有往年题时可作落地例：原题 → 翻译 → 答题思路（在问什么 → 关键判断 → 排除）→ 核心认知。错误选项写成"诱人的错误想法"：为何看起来对、错在推理哪一步——正好作推理链里的障碍。
- **🔍 真实场景**：有子分类、平级对比、易混邻居的概念必加（首选例子形态）；高分量节点应加；简单原子概念省。两段，子标题用文字 `### 入门：…` `### 真实场景：…`。入门虚构段（约 55%，≤12 行）用最少脑力感受核心差异：一两句设定，每个分类对应一个具体动作（"加一个李四" vs "给张三升装备"），1-2 句点明取舍不拆子弹，末行映射"对应到服务器世界：……"；纯生活场景，无产品与英文术语（除概念名映射）——否则读者得先解码它们。现实段（约 45%）让读者知道"这真的在发生"：只挑一个场景，优先复用运行案例；能想象、时间线推进（T → T+1 → T+2）、覆盖多面；设定 1-2 句 → 3-5 个编号动作、括号写对应概念（"动作 1（水平扩展）"）→ Link back 小节连回概念。篇幅随分量（参考：重要对比类 40-80 行，小概念 15-30 行）。不拼盘不相干案例（每个都浅，一个都记不住）；大型真实事件只作现实段佐证。

### D. 图

- **何时用**：推理需要看见结构时才嵌，不为覆盖而嵌。复合概念在展开前先给结构图，组件多时画网状层级图；可按"架构 → 实现 → 实例"三层摆（Transformer 是架构，实现是 SA + FFN + Residual + LN 的 Block，实例是 BERT/GPT）。
- **用哪张**：同一张原图全书只嵌一次：预选到它的后面各节、后面各章改为回指首次出现处（"§1.4 那张定义卡"），不再嵌第二次。需要图时原图优先——老师选的图常比自绘好，配上讲解能媲美原讲义。候选先 Read 看 PNG 再定。不截：表格（逐格抄成 Markdown 表，可搜索、能核数；字太小的表、疑似表格的图同理——但 reader.md 偏好"原图要全"时，抄表之后紧跟原图一次，标"课件原表"，抄的表负责可读，原图负责让读者认出课件）、满屏文字页、装饰图（人像、新闻配图、logo）。自绘只在三种情况：材料没图、原图不清、多页合成一张；选了原图不再自绘同一张。自绘结构图用树形（组件 — 一句角色 — 维度，末尾标流程方向）或表格（组件 / 角色 / 维度 / 主流程位置），逐项列全，不深讲的也标 📎 列出——漏一件，读者漏学了都不知道。重复的同一图只嵌一次。一节 ≤3 张。每张非表格非装饰的候选图，要么嵌了，要么说得出不嵌的理由（重复 / 文本已完整 / 不清）。
- **怎么用**：独占一段，原图 `![<图意一句话> · 课件 L4 p28](../raw/figures/<file>.png)`，自绘图注以 `自绘 · ` 开头。图前一段引入，图后一段逐元素讲图上没写的（箭头为何这样走、谁是主角、该看哪里），不复述标签。图内英文标签不翻译，在讲解里对照。图里的公式与数值在正文出现一次，不让读者看图自取。
- **何时不用**：不贴在标题下、不图贴图、不在节末无讲解——只贴不讲等于原样搬来。

### E. 公式记法与推导

- **出场顺序**：先 1-2 段口语讲清"这一步想干什么"，公式作为思路的记法出现，再拆符号（每项在做什么，由局部重组到整体），需要时代数。直接把公式当定义贴，读者还不知道概念是什么，公式只是符号。数学定义同时给形式与维度/形状，后面的维度演算才对得上。推导可以就是主线；只有形式化严格证明降为可选并指向 reference。推导不跳步，不写"由 (1) 推得 (2)"让读者自己验。
- **记法**：排版结构承载信息用 LaTeX，只是符号用纯文本。分式、带上下限的求和积分、嵌套上下标、多行对齐推导用 LaTeX；一行无分式的等式写进段落（U = X × D）；伪码、逐步演算、ASCII 图、数值表放代码块用 Unicode 符号，块内不写 LaTeX（`\frac` 会原样输出）。display 用 `$$…$$`、独占一行、前后空行，句中改用 `\(…\)`（优先于 `$…$`，避开货币）；不用 `\[…\]`（渲染器不转换）。条件竖线写 `\mid`（裸竖线断表格）。渲染器能吃多种写法，记法仍全书统一。
- **符号**：要拆解的公式单独成行（display），不埋进长句；给汉语读音（λ 拉姆达、ϱ 变体柔）；材料两处用两套字母写同一件事时，点破"这是一个公式不是两个"。

### F. 代码与长推导分块

- **何时用**：代码或推导长过一块时。
- **怎么用**：按思考的拍子切，不按语法切；每块 ≤14 行，块前一句引出、块后讲解，写明这块对应哪个念头、承担什么意义、走到了哪——整个函数甩出等于没分。可配"白话翻译"：一段代码 → 一句做什么 + 为什么这样写。伪代码只写骨架，同样 ≤14 行。代码行 ≤70 等宽单位（CJK 记 1.66），抄原文按此折行。代码类节点可用"DIY vs 生产实现"的角度讲决策。
- **何时不用**：代码不当装饰，必须被前后推理用到。代码块 + 表格约占每章 ≤20%（>30% 告警），否则挤掉推理链。

### G. 表格、比较与决策树

- **何时用表**：同一组维度上的并列对比、数值表、what-if 结果、速查汇总；合并对比用表或并列结构突出差异。术语对照用"原词 + 人话"双列。
- **怎么用**：列数与单元格长串的上限是 render 的版面常量（A5 只装得下 4 列、无空格长串 ≤36 字符）；超了就拆两张或改列表，长标识符写进正文。
- **何时不用**：表不替代叙事，只在叙事后作速查；背景节不复述已出现的表。
- **比较要开盒**："X 比 Y 更……"说清比的维度、差多少、各自适用、代价；评估类内容给几条轴与每轴含义。提到外部方案也开盒讲它改进了什么，只点名不算讲。
- **决策树**：材料有平级选型时，特征表让人"每个都觉得对"，决策树让人按序排除到唯一答案：第一问是最高优先判断 → 是则结论 A，否则下一刀……最后默认结论；逐刀递进不并列；附 ⚠️ 写最常选错的选项为何看起来对。

### H. 先想一想（🤔）

- **何时用**：关键结论前、读者手里的材料已够 TA 差一点自己想到时。形态按需组合：辨析易混概念、给场景判断会发生什么（可借运行案例）、用自己的话说存在意义、判断陈述对错（专治常见误解）。
- **怎么用**：一两句问题，答案随后在正课给出，顺序不反。
- **何时不用**：读者还推不出时；它不是习题集。

### I. 块类型词汇表

| 块 | 性质 · 读法 | 只装什么 |
|---|---|---|
| 正课（无标记） | 主线 · 专注读 | 推理链、定义、公式、材料数值与例子 |
| 🧭 导读 | 预期 · 章首必有 / 节首可选 | 念头或分量 · 时长 · 读法 |
| 🧩 核心角色 | 锚点 · 低负载 | "X 是一个……器" + 输入/输出 |
| 💡 打个比方 | 辅助 · 没懂时读 | ≥3 行的类比 |
| 🔍 真实场景 | 落地 · 中等专注 | 入门 + 真实场景 |
| 🤔 先想一想 / 先猜 | 邀请 · 低负载 | 一两句问题；作"先猜"用时答案就是紧接的下一段 |
| ⚔️ 押一注 | 出手 · 章首挑战 | 情境题 + 3–4 个常见直觉选项；揭晓（另起一页）：对错 + 错因 + 引出正文；附跳关链接 |
| 🗺️ 路线 | 预期 · 节首必有 | 一行箭头：本节各段的用途 |
| 🧠 心智卡 | 收束 · 收章第一块 | 大图位置上的问题 / ❌ 错答 × 2–3 / ✅ 正解 + 因为 / 一句话 |
| 🌳 块小结 | 收束 · 块末章、心智卡之后 | 这块在问 / 合起来的答案 / 往上挂 / 往下接 / 一句话；卡下接小树图（框 = 块内各章，"留下：…"） |
| ⚠️ 陷阱 | 校准 · 中等专注 | 会算错/写错的机制 |
| 📌 定义 | 校准 · 回查 | 一句精确定义 |
| 📏 要懂多深 | 校准 · 低负载 | 三档投入 |
| 📎 小补充 | 校准 · 知道存在即可 | name + 作用 |
| ☕ 换气 | 材料外 · 累了先读，跳过不影响主线 | 画面钉子 / 荒诞小剧场 |
| 🎓 师门心法 | 材料外 · 往上一层，可跳 | 所以然 |
| 📍 材料外说明 | 标记 · 材料外节首 | 来源节 + 纳入理由 + 层级（前置节换成"前置 · 约 N 分钟 · 够用线"，见 section/variants/prereq.md） |
| 🔑 一句念头 | 锚点 · 前置节首 | 一两句结构念头（tree 的 mental_model），前置节的规则都从它推出 |
| ✅ 这节拿到了 | 收束 · 节末 | 内容由 section 定 |
| 🎯 考点（选装） | 校准 · 扫读 | 常见问法，≤80 字 |

这张表是唯一的标记来源：只用够用的子集，不自创标记，不写"tip/note/重要"这类空标签（换成具体内容或删掉）。emoji 只在 blockquote 首字作标记，形如 `> 💡 **打个比方**`，拼写与表一致——拼错就不上色，写完按块统计核对；标题不放 emoji（破坏 PDF 目录）。verify 与 compile 的角色表与此表同源，chip 文案与配色归 render。别的模块只用这张表里的块名。一块一性质（☕ 不讲机制，🎓 不写考点，📌 不放故事），一种标记一种语义。

- **🧭 导读**：开不开、开在哪由 chapter 定，这里只定形式。章首每章一条：`> 🧭 本章: {那一个念头} · 约 N 分钟`；节首可选、全书统一：`> 🧭 本节: {核心|常规|背景} · 约 N 分钟 · {读法}`。分量（多重要，来自 tree weight）与负载（多难读）是两件事：分量印出来；负载评级不印，由读法换成该带的状态（"需要纸笔跟一遍"）。全用文字（emoji 连排在 A5 上糊成一团），不写出处。时长唯一口径：正文字数 ÷ 速率（轻 300、中 250、重 180 字/分，对应通读、停下对公式、跟算回看）向上取整，每张 ASCII 图或表格 +1 分钟。
- **🧩 核心角色**：一句话锚点，忘了公式靠它重建。只给有明确"吃什么吐什么"的机制（Self-Attention 是上下文表示生成器；MapReduce 是数据并行调度器），格式"X 是一个[……]的[生成器/调度器/求解器……]"，输入/输出写成列表项。纯定义、分类、记号、术语不开，只写 📌。🧩 说流程里承担什么，📌 说精确定义；两者成了同一句话的两种说法时删 🧩。
- **📌 定义**：一句话精确定义，回查用，≤2 行，超过就是写成了备份；不复述正文刚出现的整张表或公式。推理链常在末尾才得出定义，此时 📌 就是结论的落地句，可与首次给出合一。
- **⚠️ 陷阱**：讲怎么错（机制），每条标来源。取材信号：材料里"注意区分 / 很多人误以为"（首要来源）；"X 必须满足 Y"处的易混条件；位置/角色对调（mapper 端 vs reducer 端）；数量关系（task 数 = R 而非 key 数）；动机/因果（落盘为容错而非性能）；单位口径与分母取错；材料笔误（照抄原文 + 算式说明）；老师警告的边界；常见符号错误。值得点的"对"是反直觉但对，值得点的"错"是看着对其实错。没有就不写。
- **📏 要懂多深**：三档"理解够用 / 工作够用 / 深入研究"（依 reader.md，不设考试档）。在读者会问"要懂到啥程度"处开：内部机制或架构图（要记吗）、偏僻学术概念（值得深究吗）、更高级或更底层的话题（值得花时间吗）、新名词频繁出现（得多熟）。句式如"不用深究""组件名不用记""想深入查……"。告诉读者该投多少精力，读者才不焦虑漏了什么。只在核心节开；非核心节的偏门概念用 📎 或 📍 里一句深度提示代替。
- **📎 小补充**：材料细节（产品名、偏门变体、学术 detail）丢了读者在外面一脸懵，塞主线则密度爆炸。在相关处插 1-3 行，只写 name + 作用，不展开，留"想深入查 X / 知道存在即可"（`📎 NTK-RoPE / PI：拉长上下文的两种位置编码改法，知道存在即可`）。
- **☕ 换气**：用最低脑力给概念钉一颗记忆钉子，80-200 字。画面钉子（能在脑里放映、与概念同构）或荒诞小剧场（ρ = 0.99 的服务器像只剩一个数硬币收银员的超市，多来一人队伍翻倍）。以一句 link back 钉回概念。禁区：零信息寒暄、无关段子、新术语或机制、编造行业细节（年份、公司数字、"某某说过"——记不准改虚构小剧场）、代替深度例子。不写"行业趣闻"（禁编造后只剩心虚的口吻）；从业者经验进 🎓。
- **🎓 师门心法**：往上一层，不是更多细节——机制层讲取舍，心法讲这类选择为何存在；混写读者分不清必修与顿悟，故单独成块。只给核心机制、定律、设计选择；术语/分类/记号类与材料外节点跳过。取材判据同 section 的心法判据（推理链要用的原因进正课；连结论都没给 → 不写）。三透镜选一、最多两个：让机制不得不这样的约束或不变量；同构指认（哪类思维动作、本书哪里再现）；从业者的判断（课本不说的"但是"，含被内行追问细节怎么答：参数依据、指标判读、可改进处）。格式：标题写"所以然"不写"然"；段 1 课本停在哪，段 2 上一层看是什么（推理不断言），段 3 可选、这招还在哪出现。150-400 字，前辈私下聊天口吻；内容边界同 core 的补充规则（无年份、引语、外部数字）。放在真实场景之后、节收尾之前。
- **教学简化版 vs 真实世界版**：透镜 3 的一种写法，用于实现类核心节末。材料实现经典算法、自造业界已有的轮子、或做了工程简化（单 batch、单 head、假设 mask）时开；纯数据 IO/可视化、成熟库标准调用不开。结构：材料版本 → 简化在哪 → 工程缺什么 → 业界版本改进了什么（开盒）→ 简化版为何仍值得学（思想、底层、权衡）。
- **🎯 考点**：默认不启用；仅当 reader.md 声明备考目标且范围含考试材料时启用。讲这个知识点通常怎么被问（问法、陷阱方向），≤80 字，机制留在正课或 ⚠️；不写分值、频次、"必考"（core 禁止清单）。

**质地下限**（分量是前提）：核心节 = 正课 + 至少一种辅助/例子块（💡/☕/🔍）+ 至少一种校准块（📌/📏，启用时含 🎯）；常规节 = 正课 + 至少一种校准块，⚠️/📎 也算一种质地；背景节写短，最多一个校准块，不开 📏，不硬配 💡/☕；速查汇总型节（公式速查、术语总表、决策树汇总）只需表格 + 校准块。下限是"漏了落地"的报警器，不是排版模板；配齐块不是质量，分量对才是。宁可两种质地，也不把正课包进 💡 假装辅助。

**预算**（按章、按字符）：☕ ≤8%，🎓 ≤15%，超了删最弱的；每章 🎓 至多一个，放在本章最重的机制上。

### J. 出处、术语与首次出场

- **出处**：节标题下的机读注释 `<!-- nodes: … | sources: L4 p27-29 -->` 让读者读到哪节都能翻回材料哪几页；正文指回材料用脚注 `[^L4p28]`。页码只作出处、方便回查，不替代内容，不进标题和导读条。材料例子附出处脚注；回指前文用 book 统一的跨章引用。
- **深度提示**：核心节给一个脚注指向延伸材料（材料的 references/、大纲列的参考书）。
- **术语**：首现中英并列、自造速记名当场拆开，规则归 core；落到器件上就是：表格里不丢原英文术语，原话引用保留英文、解读用中文。
- **产品/工具首次出现**给四要素（出身、定位、使用感、独特性），首次出现表归 book；材料只给名字时按 core 降为定性定位 + ⚡。

### K. 材料外内容：三级标记与深度

> 前置节（external prerequisite）的整节标记、深度与篇幅由 `section/variants/prereq.md` 覆盖（V-PRE-12、V-PRE-13）；下面的规则对延伸节与行内/整块补充照常适用。

补充围着材料内容转，不另起话题。三级标记：

- **行内级**：正课句子夹一个材料外的事实/术语/数字，句边标 ⚡；给材料的表加行时单独标 ⚡ 另起。
- **整块级**：☕/🎓/💡 天然是材料外，块类型即标记，块内不逐句 ⚡，同样禁止编造；读者累了可整块跳。
- **整节级**：tree 中 external/外延节点所在节，标题加文字后缀"（材料外）"（标题不放 emoji，故不用 ⚡），节首 📍 写明不在材料范围、从哪节引出、纳入理由（被哪个节点 requires：材料默认你会，或这里是理解断点）与层级。

深度按必要性递减（材料内核心概念无标记、全步走完、篇幅 100%）：**⚡ 理解必需**——步骤走完但简洁，纳入理由与简短 🔍 必有，🎓 可选，约 60-80%；**⚡⚡ 有帮助的邻居**——入口问题 / 定义 / 一个 alternative / 收尾（含深度提示）必走，例子简短，🔍 可选，不开 🎓，约 30-50%；**⚡⚡⚡ 知道存在即可**——一句定义 + 一句"想深入看 X"，2-3 行，不开 🔍。三级都要有精确定义（📌）；⚡⚡、⚡⚡⚡ 必有深度提示——对材料外内容，"了解到什么程度"比内容本身更重要。

## 判断准则

1. **推理 > 装饰**：拿不准要不要一个器件，问"删掉它，下一步推理还迈得过去吗"；迈得过去就删。
2. **诚实 > 丰富**：凑不齐块就少；材料内容的唯一载体永远不是附加块。
3. **原文 > 转述；需要图时原图 > 自绘；运行案例 / 材料例 > 自编。**
4. **同构 > 贴近生活；一个连贯场景 > 拼盘；一个例子串链 > 多个孤例。**
5. **保真 > 完整**：记不准就不写，四要素降级，☕ 改虚构。
6. **⚠️ 还是 🎯**：看这块讲错法还是讲问法，不看节点有没有考点标记——否则考点多的课 ⚠️ 被清空；同一件事可两边出现，内容不重复。
7. **新器件**：先答它承担推理哪一步、块性质是什么、删掉后正文是否仍完整；答得上按 MODULE 扩展点加进词汇表与 EXPECT，答不上就是装饰。
