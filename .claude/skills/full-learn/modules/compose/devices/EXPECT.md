# compose/devices — 验收

本表只列人要做的条目（self / cold-read / 脚本未实现）；纯脚本检查在同目录 `GATES.md`，写作时不必读。

脚本名以 audit PARADIGM「脚本注册表」为准：成书检查在 `verify_book.py`，版面常量检查在 layout_check（尚未实现的检查标 `script(todo)`；可从 `scripts/verify_teach.py` 对应逻辑移植的已在备注列出）。按章运行。
