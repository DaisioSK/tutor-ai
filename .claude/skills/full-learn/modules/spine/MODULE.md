# spine — 叙事脊柱

## 职责
在科技树上选一条拓扑序，使每一步都是读者此刻心里已经在问的问题；切章（一章解锁一项能力）；选定贯穿全书的运行案例。决定全书"顺不顺"。

## 继承 / 覆写
继承 core。覆写：无。

## 输入
T2 `tree.json`；T1b `lecture-flow/`（讲者脉络，默认全序与例子的来源）

## 输出
T3 `spine.md`

## 依赖
tree

## 公开方法
1. `case` — 选运行案例（优先老师的开场例子）
2. `order` — 选拓扑序：默认沿讲者脉络，偏离逐条记理由
3. `chapter` — 切章、定每章解锁的能力与章入口问题
4. `cells` — 每节填四格：入口问题 / 凭什么现在能懂 / 解锁了什么 / 留下的新问题

## 检查点
产出后 ⏸ 交用户审阅。

## 扩展点
多卷本 → 在章之上加"卷"，卷 = 一组解锁同一大能力的章。
