# render — 范式

## 一句话

PDF 是这本书唯一的成品，而它是在手机上一页 A5 一页 A5 顺读的：render 用确定性的离线工具链把 `book/*.md` 编成一本"每个字都排得出、随时知道自己在哪"的书——排不好就响亮地失败，编完亲眼翻一遍。

## 理论

**1. 屏幕决定写法。** 读者拿手机从头顺读一本书，不是开卷时翻找。A5 宽 148mm、左右边距 12mm、正文 10pt、代码 DejaVu Sans Mono 8pt——这几个数一定，就反推出写作上限：代码块每行 ≤ 70 等宽单位（CJK 按 1.661 折算）、表格 ≤ 4 列、单元格无 > 36 字符的无空格长串、页眉里的章短名 ≤ 8 字、节中文标题 ≤ 12 字。版面限制回流成写作约束，而不是编译时缩字号硬塞。这些常量与编译器 CSS 耦合：改边距或字号，门禁常量一起改。

**2. 确定性离线工具链：宁可响亮失败，不静默降级。** WeasyPrint 只排 HTML/CSS、不跑 JS，所以 MathJax/KaTeX 用不了；它也不支持 MathML，matplotlib mathtext 排不了 `\text{}` 里的中文，texlive 太重。于是自带零依赖转换器 `latex_to_html.py`（Unicode + sub/sup + CSS）；mermaid 同理只解析受限子集，编译不联网。最危险的失败是静默的，PDF 看起来"差不多"：公式原样印成源码、整张表塌成一行、脚注印成 `[^a]`、原图全被标成"自绘"。所以转换器遇到不认识的命令原样保留成红色 `m-unknown` 并上报，由门禁转成 FAIL；每一条已知的静默路径要么修掉，要么改成上报。

**3. 编译器只排版，不判内容。** 内容对不对归 audit，排版对不对归 `layout_check`，编译器本身两样都不查。漂亮的 PDF 最容易掩盖漏页，所以顺序固定：内容门禁和排版门禁全过，才编 PDF。

**4. 导航是理解的一部分。** 读者在任何一页都该知道自己在哪、在看哪部分；大纲只在开头出现一次，读到第十几节早忘了。导航因此分层：书首全书骨架图与卷骨架图（全局去向）、章首骨架图（本章的几个大概念与关系）、每页页眉面包屑（章 · 大概念 · 节）、可点目录、一点就跳的交叉引用。全部从已写下的结构派生（h1/h2、节注释 `nodes:`、`tree.json`），不让作者另写第二份——派生的永远和正文一致。

**5. 源码门禁看不见成品。** 有些坏只存在于排出来的页面上：整页只剩一个标题、表格挤成一字一行、裁图在 A5 上看不清、emoji 字族接管数字（`CS1234` 排成 `CS 1 2 3 4`）、span 伸出页边。所以检查分三层：编译前查源码、编译后查 PDF 文本层、最后用眼睛看。

## 方法

### 0 · 前置

每章 MD 已通过 audit 的内容门禁和本模块 `layout_check`，任一 FAIL 不编。命令都在仓库根目录下跑（Windows 用户建议经 WSL）：`which python3 || which python`，再搜常见路径；依赖 markdown + weasyprint + pymdown-extensions，缺失时打印对应的 `pip install --user --break-system-packages …`。

### 1 · compile — 组书

```
python3 .claude/skills/full-learn/scripts/compile_story_pdf.py output/<课>/full-learn
#  → output/<课>/full-learn/book.pdf          全书（编完自动跑 verify_pdf.py）
#  ... --only 3 [--with-front]                单章预览 → book-ch03.pdf，不覆盖全书（⏸2 样章审阅；可带书首）
#  ... --no-goals                             不印 ✅ 目标块（MD 里照留）
#  ... --no-gate / --no-verify                跳过编前门禁 / 编后检查（只用于调试）
```

文件顺序 `00-front` → `NN-<slug>` 按 N → `99-back`；课程名取 `book_dir.parent.parent.name`。原地编译，`base_url` 设为 `book/`（并开 `presentational_hints`），`../raw/figures/` 才解析得到——拷到临时目录编译，图全断。无 MD 直接退出；成功打印文件清单与 PDF 大小。

成书结构：封面（课程名 + 书名，不残留"故事链"、KP、"作业预备"、考试口径等别的产品用语）→ 自动生成的可点目录（MD 不手写目录、无 index.md）→ 书首章表（章 / 解锁能力 / 阅读时间 / 最重节，从 spine、tree 分量与字数派生）→ 科技树图 → 书首正文 → 各章（每章新起一页）→ 书尾 → 自动术语索引（节点中英文名 → 所在节）。

全部 MD 写完自动编一次；之后任何影响叙事的补充都重编，PDF 不落后于 MD。

### 2 · 转换 — MD → HTML

顺序有讲究：先转数学、再跑 Markdown（代码围栏内一律不转，那里的 `$` 是内容；引用块内公式保留 `> ` 前缀不掉出框）；mermaid 先抽成占位，Markdown 转完再换回 HTML。扩展：fenced_code、tables、toc、attr_list、sane_lists、pymdownx.superfences，以及 **footnotes**（T4 的 `[^L4p28]` 靠它，否则原样印出）。节下 `<!-- nodes … -->` 注释原样透传、PDF 不可见。

预处理填平 Markdown 的坑：只隔一个空行的两个引用块强制拆开、各自着色；引用块内文字行后紧跟列表时补空 `>` 行；嵌套引用继承父块边色；代码外的 `<s>`、`<eos>` 等记号包成行内代码，否则 `<s>` 把后文全变删除线。写作侧推论：输入/输出这类并列行写成列表项，否则被并成一段。

数学：识别独占一行 `$$…$$`、跨行 `$$` 块、`\(…\)`、句中 `$$…$$`（按行内）与 `$…$`；`\[…\]` 不在识别之列，只会被残留检查报出，所以写作侧不用它。单 `$` 收紧（开后闭前无空白、不跨行、≤ 120 字符、不与 `$$` 相邻，同行有 `$$` 不跑单 `$`），再判货币（含反斜杠必为数学；数字开头无等号为金额；含 `_^{}=` 为数学；`P(e)` 函数式放行）。覆盖面见 `SUPPORTED`：希腊字母全表（含 var）、五类符号、组合字符变音、直立算符与 `\operatorname`、大算符（display 上下摆限、行内用上下标）、空白命令、字体命令（`\text` 内中文走 CJK）、结构命令（frac/binom/sqrt/花括注/underset/boxed/cancel/substack…，CSS 画分数线、√ 加上划线、边框模拟括注与框）、对齐/分段/矩阵环境渲为无框表格（aligned 奇列右对齐偶列左对齐，cases 带左花括号，未知环境上报）；只管 TeX 尺寸的命令丢弃，`\left`/`\right` 只出定界符，`\i`/`\j` 当字母，上下标附着试探跳空白、未命中回退。关键取舍：`\mid`、`\vert` 出 U+2223、`\Vert` 出 ∥，从不吐 ASCII 竖线——数学先于表格解析，真竖线会让表格多切一列、整表静默退化。已知静默缺口（`\sqrt[n]`、矩阵不画括号、array 列格式印进首格）要补成支持或上报。样式：display 居中 10.5pt、行高 2.0、不跨页；行内 nowrap；字体链 Cambria Math → STIX Two Math → DejaVu Serif → CourseCJK。写作只用 `SUPPORTED` 里的命令，不认识的要么改写、要么补进转换器；调单个公式用 `python3 latex_to_html.py <file|stdin>`，未知命令进 stderr。

### 3 · 导航

锚点：章 `ch-N`，节 `sec-N-M`（正则认 `§N.M`，标题含行内代码也能抽到）。面包屑从 `# 第 N 章 <标题>` 与 `## §N.M 中文 (English)` 派生为"第N章 短名 · <大概念> · §N.M 中文"，大概念取本章骨架图里该节所在 subgraph 的标签（没有骨架就退回"第N章 短名 · §N.M 中文"）——去掉英文副标题，它正是页眉被截断的原因；页眉一行约 42em（`CRUMB_MAX_EM`，与 @page 边距和页眉字号耦合），超长时先把大概念截成"前几字…"，仍超就去掉大概念；盖在每个节标题前并设为 running header（`string-set: crumb content()` + `content: string(crumb)`；`string(crumb, start)` 在 WeasyPrint 下为空）。目录含书首 / 各章 / 各节 / 书尾，取 h1、h2 文本剥标签，全部可点。正文的 `第 N 章`、`§N.M`、节点 id（`N-12`，由全书 `nodes:` 注释建 id → 节锚点映射）自动变跳转链接，橙色点线下划线；MD 文件链接（`03-x.md`）改写成锚点，IDE 与 PDF 都能跳。pre/code/a/h1-6/属性里不替换；标题里的 §N.M 只是跳转目标。

骨架图（首行 `%% skeleton` 的 mermaid：章骨架、书首的全书骨架与卷骨架）离线画成 PNG（`skeleton_figure.py`，matplotlib，不联网、无 graphviz）：每个大概念一个圆角框，框顶概念名（粗体），框内逐行列子题与对应的节/章（`:::core` 用强调色 + ★）；概念之间画箭头并标"关系词：短语"（`-.->` 虚线）；包含/递进/因果/前提/应用做最长路分层，并列/对比放同层，跨层边绕行；`flowchart LR` 层横排、TB 竖排，概念 > 4 个、有同层或跨层关系、或 A5 正文宽（124mm）放不下时换 TB；图按印刷尺寸出，字号 ≥ 8.5pt（正文 85%）。图下说明按图的种类给："本章骨架：框是大概念，框内是子题与对应的节；箭头上是它们的关系。"/"全书骨架…"/"第K卷骨架…"（subgraph 标签以"卷"开头 → 全书；子题是"第N章" → 卷，卷名取图前最近的标题）。matplotlib 不可用时退化为 HTML 卡片并告警。骨架图不算课件原图，元数据 `skelfig=` 供 verify_pdf 扣除。

旧格式的章首地图（节点标签以 `§` 开头，compose/chapter 改骨架之前的写法）仍渲成分段卡片 + 按分量上色的 § 胶囊：只用离线子集（subgraph + 节点 + 边 + class，不认识的行忽略），subgraph 标签写"段名 · §范围"、段名 ≤ 8 字（章内不分段就用章短名），节点标签 `§N.M 短名`、短名 ≤ 12 字，类名 core / 不标 / bg / skip；相邻子图之间的边画成 ▼，可带标签。MD 里保持标准 mermaid，IDE/GitHub 照常渲染，PDF 侧另行解析。

科技树图：树是分层 DAG，"段里排卡片"画不出它，所以离线生成分层图（`tree_figure.py`：书首里的科技树 mermaid → 否则 tree.md 的 mermaid → 否则 tree.json 的 requires；最长路分层 + matplotlib 出 PNG，不依赖 graphviz；matplotlib 不可用时退化为分层列表并告警）。书首里的 mermaid 原位换成横版 A5 图页，紧挨的 `## 科技树` 标题并入该页；书首没写就在全书一览后自动插一页，按生成元 / 高分量 / external 着色、类名与 `tree.md` 一致（印出的图例用读者的词：根思想 / 材料外前置，不印内部代号），放在书首目录之后（可横向 A5）。mermaid.ink 只能一次性出图存盘，编译本身不联网。

### 4 · 图与块

独占一段的图包成 `<figure>` + 图注（取 alt）：alt 含 `课件 <短名> p<N>` 的挂"课件原图" chip（白底细框），以"自绘"开头的挂灰色"自绘" chip；图不跨页、高 ≤ 62vh、图注 8.4pt 左对齐；路径相对 `book/` 解析。

块的视觉签名由编译器统一：按引用块首标记给角色类名（角色表与 devices 块词汇表同源，verify 与 compile 读同一份配置），每种块一个固定配色与顶部小标签（灰青细条、靛蓝粗左边、琥珀、奶油底虚线框……），读者一眼知道该带什么状态读。写作只管用对标记——拼写就是样式开关，拼错不上色。标签文案由 render 定，不带考试口径（🎓 不手写副标题）；📌 定义上蓝色速查样式；✅ 目标块压成一行小字、不挂 chip，`--no-goals` 可不印。引用块与地图卡片不跨页。

### 5 · 字体

CJK 自动探测：WSL 下 Windows 雅黑 → 黑体 → 宋体 → Noto CJK → 文泉驿 → AR PL；首个可用者注册为 `@font-face "CourseCJK"`，正文回退链 YaHei / PingFang / Hiragino / sans-serif。找不到只告警、照出 PDF，并提示 `fonts-noto-cjk` 或挂载 Windows 字体。emoji 只保留带 `unicode-range` 的 CourseEmoji，其余交给 fontconfig 回退——不限范围的 emoji 字族一旦进 font stack 就会接管数字。编译后自动检查字体分配。

### 6 · 版式

`@page` A5，边距 16 / 12mm，页脚"页码 / 总页数"；封面、目录后与每章前分页。h1 章（大字号 + 蓝色双下划线）、h2 节（蓝侧条 + 浅蓝底）、h3 子题，都 `page-break-after: avoid`。正文 10pt、行高 1.6、两端对齐；pre 8pt，`pre-wrap` + `break-word` 兜底不横向溢出。表格可跨页、单行不劈开、表头每页重复（`thead` 为 `table-header-group`、`tr` avoid）——整表 avoid 会把标题孤留上一页。单元格 `overflow-wrap: anywhere`，格内行内代码 `break-all`。嫌页数多：先压行距与间距、再压字号，正文 ≥ 9pt、代码与图注 ≥ 7pt；只动 CSS，不删内容。

### 7 · layout_check

```
python3 .claude/skills/full-learn/scripts/verify_teach.py output/<课>/full-learn book/03-<slug>.md --layout-only
```

只查排版、不查结构，目标形态是直接接受 `book/` 目录、逐章汇总。源码层：围栏数为奇数（未闭合会把后文当代码）；表格行先模拟数学转换再数竖线；表格 > 4 列；单元格无空格长串 > 36 字符 WARN（跳过分隔行，链接只算文字）；代码行宽 > 70 单位；ASCII 图右边框错位（连续框线行渲染宽差 > 0.5 且边框前含 CJK，改左锚定或去中文）；不认识的 LaTeX 命令列名；残留 `$$`、`\(`、`\[` 或像公式的 `$…$` 给行号（`$$$` 散文与金额排除）；行内公式过长；章短名、节标题超长。通过时打印回执"数学: display N 块 · 行内 M 处"。PDF 层（编译后）：任一 span 的 x1 > 页宽 − 8pt 即溢出（拆长行或缩表列）；字体分配。

### 8 · 看成品

打开 PDF 抽查（Read 页面）：有没有整页只剩一个标题；有没有表格被压成一字一行；裁图在 A5 上字是否看得清（看不清的表抄成 markdown，回 compose 改）；原图标签有没有被裁掉；页眉与目录跳转是否正常。

### 9 · 交付

报告章数、总阅读时间、页数、PDF 路径与大小、audit 结论。

## 判断准则

- 内容完整 > 页数少；显式失败 > "差不多"的 PDF。
- 派生 > 手写：导航信息能从结构推出就不让作者另写。
- 手机可读 > 信息密度：A5 放不下时回到写作拆表、断行、换写法，不把字号压破下限。
- 补转换器 vs 改写法：标准且会反复出现的 LaTeX 命令补进转换器；一次性的冷门写法就地改写。
- 离线确定 > 方便：任何要联网或跑 JS 的环节都不进编译路径。

## 反例

- 三种公式写法并存而编译器无数学扩展，145 个公式块印出源码；表格行内用 ASCII 竖线，整表塌成一行——静默降级（理论 2）。
- emoji 字族混进 font stack，`CS1234` 排成 `CS 1 2 3 4`——只在成品里看得见（理论 5）。
- 大纲只在讲首出现一次、页眉段名过长被截断——读者中途迷路（理论 4）。
- 为压页数删内容，或拿漂亮 PDF 掩盖漏页——编译器越权（理论 3）。
