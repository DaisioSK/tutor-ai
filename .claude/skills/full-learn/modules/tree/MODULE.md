# tree — 科技树

## 职责
建全范围的认知结构：有哪些节点、谁依赖谁（懂什么才能看懂什么）、哪几个是生成元、终极理解是什么、每个节点多重。这是本 skill 的核心资产，后面一切顺序与分量都从它推出。

## 继承 / 覆写
继承 core。覆写：无。

## 输入
T1 `raw/`；可选 `reader.md`（读者起点覆写）

## 输出
T2 `tree.json` · `tree.md`

## 依赖
ingest

## 公开方法
1. `harvest` — 从材料逐页抽出节点（含材料默认你会、但没讲的隐含前置，标 external）
2. `link` — 建理解依赖边（不是课件出现顺序）
3. `distill` — 找生成元与终极理解
4. `weigh` — 由依赖闭包算分量
5. `draw` — 出 tree.md 与科技树图

## 扩展点
多范围合并（两门课共用节点）→ 节点 id 加命名空间。
