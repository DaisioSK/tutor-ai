# core — 范式

## 一句话

借一个高手的脑子给读者：材料是地基，一字不能假；作者的理解是加在地基上的推理，让读者只捧着这本书从头顺读，就像跟着作者把整个范围想了一遍。

## 理论

### 1. 书的本质是"借脑"，不是"转述"

读者的瓶颈不是读不到原文，而是读完没解读、满脑问号。书的意义是让熟手的理解在阅读中出现在读者脑子里。所以作者写的不是结论清单或报告，而是能跟上的心路历程：熟手从看到问题、看穿要害、搭大图到落细节，依次想了什么、为什么、在哪卡过、怎么绕过。旧版"死记硬背过考"的根因正在于此：只有结论堆，没有推理骨架。

由此推出"通俗"的真正维度：**通俗在推理上，不在措辞上**。措辞口语、推理跳步，读者依然看不懂；每个公式都能在三步内从一个画面推出，用词专业也跟得住。AI 时代知识与实现廉价，值钱的是思路与认知框架；但廉价不等于不给：推理链要的一步不少，无关的一字不多。

好书好在展开方式、节奏、讲述角度与推理链，而非亮点；不依赖实时反馈，读起来顺、爽，像一个从零到完整理解的连贯故事——人记住的是故事，不是分类表。

### 2. 作者与读者是一对固定的人

**作者**：行业深耕多年的专家兼耐心的前辈，坐在读者对面，用"我"对"你"说话。TA 不展示知识，而是从最简单的事开始（开篇尤其入门为先），带读者走最短路径建立准确、完整的核心认知；TA 在场，说出当时的动作和理由（如："我先看测试，因为题面会骗人，测试不会"），指着读者眼前的具体对象说话（"这个 √d_k 不是装饰"），不站讲台泛泛宣讲。

**读者**：聪明，但对这个范围一无所知，把读者当作看了原文也没看懂的小白；默认画像是 AI 行业半工半读、时间紧的人。读者手边只有这本书，顺序读，随时会走开，半年后忘了要能重新进入。TA 要的不是把知识装进脑子，而是**最小但完整的心智模型**加一张随时能查的认知地图（书首科技树图、书尾全书一张图、关键词索引），从而能和内行无障碍交流、问对问题、按图索骥。通俗为了读得下去、忘了能回来，专业为了实战不空洞、有"我懂底层"的细节：通俗引路，专业给深度。

这对人是固定的：用户说"备考/答辩/探索"只改变材料外补充放多宽，不改变写法——备考不是考点清单，答辩不是 Q&A 列表，探索不是百科全书。

### 3. 材料是地基，表达是加法

给定材料的全部就是范围，学完它是目标，不按考题反推只学一部分。材料的每个知识内容——定义、公式、表格、算例、老师的边界警告——都要落到某个树节点并进入正文。无标记的正文读者默认是材料、默认信任，所以**漏标比多标严重**：假数字进了学习材料就进了读者的答卷和工作，风格再好也抵不过一个编造。

一切表达（画面、类比、节奏、所以然、补充）都加在完整材料之上，不替换它：删掉全部外部补充，正文仍须完整覆盖材料。任何节奏或器件规则一旦导致材料内容被删、被弱化、或只活在补充块里，该规则在该处自动失效。全 skill 冲突裁决序：**保真与范围（core）> 推理链（section）> 节奏（chapter）> 器件（devices）**。

### 4. 范围是给定的，材料外按刻度准入

材料外内容分三类：理解主线必需、材料默认你会却没讲的前置（必收，讲到够推理用）；发散刻度内的延伸（按刻度收、标记、深度逐层递减；它是计划内容，不是离题）；刻度外的（不写）。连同材料核心这四档，决定的是树上节点的 kind 和正文带不带标记，不是临场应答策略。刻度不在对话里调，开工时一次推断、落盘、全程使用。

外部补充的唯一正当性是**把材料某个结论往上抬一层**：讲范式来源与思路，让读者从"会用"走到"会造"（遇新问题能自己推出下一步）——这正是"背会公式"与"和内行无障碍交流"的差距。材料连结论都没给的，不凭空讲。

### 5. 每一个字都要为读者此刻的理解付费

篇幅按"读者从现有认知走到这里还差多少"给，不按页数平摊。覆盖是下限不是均摊：每页都讲到与每页讲一样多是两回事，后者等于没重点。好例子不吝啬，同一意思不说两遍；知识点多就讲透，不压字数也不注水。只引入理解必需的新概念；删减判据是"这句对问对问题、按图索骥有没有帮助"。密度过高同样浪费：读者要停下反复消化，节奏就断。

## 方法

### 1. 开工：定读者与范围，落盘

从用户请求与材料类型推断读者起点和发散刻度，写进 `reader.md`；范围声明只写课程名与覆盖范围（范围一变整本就废）。刻度三参数：`divergence_layers` 0–3（可离材料多远）、`divergence_breadth` 1–8（每层每概念最多展开几个）、`relevance_threshold` 严格/中等/宽松。

锚点仅供参考：讲义边界清楚偏收（0–1 层 / 1–2 个 / 严格）；代码仓库要讲背后的"为什么"，居中（2 层 / 一层 ≤5、二层 ≤2 / 中等）；无材料的空白话题全靠发散（3 层 / 8·5·3 / 宽松）。再按信号挪档：备考、时间紧收一档，答辩居中，想彻底搞懂、探索放一档；有相关背景就覆写起点、跳过基础，完全小白先收、每层讲透再开下一层。"不要发散"即 0 层：不写任何发散补充，但理解必需的前置不算发散，照收；未声明取中等默认。这是综合判断，不是查表。

关键前提（范围、读者起点）缺失又推不出就问用户，不猜；超刻度的内容在脊柱检查点提示用户可调刻度。各模块开跑前检查上游产物（T1/T2/T3），缺了提示先跑对应命令。

### 2. 落笔：站在作者的位置说话

每段开头给一个停留的理由；写动作和理由，不陈列结论；画面与类比先于术语（先说"分块算、边算边累加、需要时再算一遍"，再给 FlashAttention 之名）。段短、句短，一句一件事：一段在 A5 上超过约 4 行、一句超过约 30 字，多半塞了两件事，拆开；三个以上术语不用顿号串，改成短句（"shape 要对。stride 要对。contiguity 也要对。"）。拆短是为了好跟，不是降深度。中文说人话："每分钟来几个"而非"到达强度参数"。语气是聊天的前辈，非教科书，也不过度口语化。

讲解主体是推理散文：用 bullet、表格、定义堆砌来"讲"就已偏离，重写；表格只作器件，承载材料原表或推理后的对照。

锁主线：分清主线与延伸，延伸最多一两句并标注。章节间要有过渡，但须携带信息（上一节留下的问题），不是套话。写完照这几条回看一遍文风——术语首现是否就地解释、有没有废话过渡、对读者是否说"你"而不是"我们/开发者"、标题里有没有技法名——命中就改，不靠印象。

### 3. 双语：中文做路，英文做料

判据是句子的功能而非占比：作者的解释与旁白（怎么读、为什么合法、怎么接、哪里有坑）用中文，母语省脑力；术语与原文引用保留英文作锚。两个相反的错同时防：丢掉材料原术语只剩意译；把省脑力的旁白写成英文。术语首现中英并列，之后可只用中文；英文取材料原用法，不自造英译。

### 4. 术语管控：最重要的文风规则

- 每个术语首次出现，就地用日常语言解释一句，并配一个来自材料的具体例子（"logit_scale 控制 softmax 多锐——锐 = 答案集中"）。不假设读者懂任何术语。
- 不用读者还不懂的概念解释概念，不用新名词解释新名词。前文没讲、当前也不讲的术语不出现，用白话替代；例外是材料自己在早处就用了后面才正式讲的词（如把"饱和度"列为四指标之一）：保留材料原词，首现处就地一句白话并写明落点节（"§9.7 细讲"），这是预告，不是借用；每节只依赖前面讲过的东西。
- 自造的抽象词当场拆开、配定义和例子，否则不用；产品首次出现要自报家门。
- 一个概念全书只用一个词，且用材料的词：材料叫"投影矩阵"就不改叫"线性变换"，否则读者回看原材料对不上。同章内直接复用；跨章用"前面讲过的 X"唤醒，不重讲。
- 比较级要开盒：凡说"更高级/更好/更快/更强/更省事"，同时答三问——沿什么维度比（2–3 个具体差异）、怎么做到（机制草图）、要懂多深（理解够用 / 实践够用 / 可不深究）。答不上就分别描述 A 和 B 让读者自己比——不开盒的比较级在读者脑里留三个黑洞，越读越糊。

### 5. 保真：每个论断都能追溯

- 每个知识论断可追溯到材料位置（`L4 p28`），页码是读者翻回原材料的锚点。与材料重合不是问题，绕开重合才是：引用、抄进来、紧跟解读。
- 老师的名词与一句话定义是定义的字面源；骨架照走，词汇、首选例子、边界警告与材料同步——这是锚点而非限制创意，不加锚 LLM 就写出"它心里的概念"。但叙事不照搬原文表达，用作者自己的口语重写。
- 数字：材料表格的数值与行项逐格照抄，表述可口语化，阈值不动，行不增删。材料说定性就保持定性（禁伪精确）；没有来源的数用定性表述。由材料数值做的衍生算术合法，但必须写出算式，只报结果按伪精确处理。假想演示数字须声明"编个数演示"，只能另加，不替换材料算例。纸面上的数要能复现纸面上的结果：读者照着写出来的中间值按计算器，得到的就是书里写的下一步——四舍五入让两个不同的量（0.327 与 0.333）看起来相同时，多留一位或保留分数。
- 材料笔误：照引原值，用算式说明"疑为笔误"并给正确值，不静默改。
- 出处不伪造：材料外的例子、引语不说成"老师讲的/课件里的"。
- 材料外的专有名词、具体数字、公司名、时间线、引语——`raw/` 里搜不到的，要么删、要么句边带外部标记（形态见 devices）。默认怀疑自己的先验；材料只给产品名，就降为定性定位加外部标记，不凭记忆补年份、公司史、用户量。保真优先于完整。

### 6. 补充：只抬一层，不讲新史

补充块只允许：可核验的数学或逻辑推理、书内交叉引用、"从业者通常"口吻的判断；禁止具体年份、人名引语、外部论文的具体数字、"某公司当年怎样"（伪史高发区）。最多一句不带年份人名的传统归属（"运筹学的传统做法"），到此为止；讲范式来源与思路，不讲史实。每个补充挂在材料某个结论上；同一内容不给第二个平行版本。

### 7. 自足：这本书是读者手上唯一的东西

顺读时无需翻材料或任何文件：每条公式、定义、状态图、例题步骤都完整落在书里；"这里不重复，见课件""去看一眼某文件"都是 bug，把解读的活推回给读者。材料是"想深入再去"，不是"不查读不下去"；出处只进脚注。自足不等于啰嗦：抄进来的是推理需要的，不是全部原文。

## 判断准则

- **保真 vs 完整/好看**：保真赢，宁可定性、标外部或删。
- **覆盖 vs 表达**：覆盖赢；一章外部补充超过约四分之一，先怀疑正文写薄了。
- **自足 vs 简洁**：问"删掉它读者会不会卡"。
- **通俗 vs 专业**：通俗化是降低消化成本而非删内容；数学与代码细节不砍，也不堆术语。
- **主线 vs 延伸**：锁主线；不能把材料结论抬一层的延伸不写。
- **读者目的 vs 写法**：考试与答辩的差异只在补充范围，不在覆盖与写法。书写的是范围本身的认知，不绑定任何一次考试：不写考务时效信息，不押题，不按考试重要度给节点贴标签。
- **具体 vs 抽象**：不 overfit 单个案例——框架层用抽象名词，具体内容当例子；本 skill 自身也如此——换一个陌生 topic，同一套方法照样能找出最精准高效的学习路径。
- **规则冲突**：按裁决序。各模块继承 core 全部范式与验收，偏离须在 MODULE.md 显式覆写并说明理由。MODULE 管做什么、什么顺序、过哪些门，PARADIGM 管怎么做好（程序性方法，非规则清单）；运行时按命令分层按需加载（SKILL → CONTRACTS → core → 当前模块，scripts 为工具层），解析输入 → 加载 → 按步执行 → 全程守 core。

**禁止清单**（命中即重写）：空洞过渡与总结废话（"总之""值得注意""总结一下""接下来我们将讨论"）、自我评价、炫耀总结能力；讲台腔（"让我们来看看"）；装饰前缀（"非常""大家都知道""实际上"）；文学性句子；重复同一意思；"我们/开发者"等泛称；元叙事——技法名（对照式发散、痛点-方案-效果、raise + reject、插件式补充、结构化叙事）与本 skill 内部代号（入口问题、凭什么现在能懂、留下的新问题、生成元、脊柱、四格，以及节点 id、分量、负载这些 tree/spine 字段）不进标题、引用块前缀、正文标签或正文表格（它们是作者找写法的查询 key，不是读者的认知），改用内容化命名（"训练显存——7B 模型为什么单卡装不下"）；考务信息与重要度标签——考试日期、地点、时长、卷面题型构成、分值、押题、"必考/高频"——书首、读法页与附录也不例外（reader.md 声明考试时，🎯 块讲某知识点的常见问法、书尾把往年题映射到节，都是知识的定位，不算考务）。

## 反例

- **语言维度的通俗 / 结论堆**：口语化描述幻灯片、贴类比，或把定义公式排成一列，推理骨架缺席——违反理论 1。
- **伪造出处与伪史**：把外部教程例句说成"老师课件里反复出现"，替模型演进补年份和"据作者回忆"——违反方法 5、6。
- **篡改与伪精确**：替换材料的真实名单、把决策表阈值 8 改成 16、把"成千上万线程"写成具体核数——违反方法 5。
- **推回读者**："详见课件 p12""去看一眼 test 文件"——违反方法 7。
- **不开盒的比较、递归解释**："Elastic 是更高级的自动化"（应说清高在反应时机、扩容粒度、决策复杂度，怎么做到，要懂多深）；抛出"结构性写死"不拆——违反方法 4。
- **均摊篇幅与元叙事**：一页图与核心公式写一样长；"§6 痛点-方案-效果"当标题——违反理论 5 与禁止清单。
