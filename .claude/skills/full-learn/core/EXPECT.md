# core — 验收

本表只列人要做的条目（self / cold-read / 脚本未实现）；纯脚本检查在同目录 `GATES.md`，写作时不必读。

每个模块完成时都跑本表。`script(todo)` 指向待实现的检查项（脚本与检查名以 audit PARADIGM「脚本注册表」为准）；实现前由作者按同一判据手工执行并在 audit 报告里记录证据。

| id | 验收标准（可判定的一句话） | 检验方式 | 不过时回到 |

| E-CORE-02 | 每个模块开跑前检查了上游产物（T1/T2/T3）；缺失时输出"先跑 <命令>"并停止，而不是凭空生成；材料外关键前提推不出时留有向用户提问的记录，没有猜测值 | self: 查本次运行日志里上游存在性检查与提问记录 | PARADIGM §方法 1 |
