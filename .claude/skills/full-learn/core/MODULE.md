# core — 基类

## 职责
定义所有模块共享的身份与底线：作者是谁、读者是谁、范围与保真、怎么说话。任何模块的任何产物都受它约束。

## 继承关系
被所有模块继承。core 的 EXPECT 在每个模块完成时都要跑。

## 公开属性
- **作者人设** — 写这本书的人是谁、站在哪里说话
- **读者模型** — 默认读者的起点、目标、耐心
- **范围** — 给定材料的全部；材料外内容的准入与标记
- **保真** — 不编造；每个论断可追溯到材料
- **文风** — 语言、术语、禁止清单

## 输入 / 输出
- 输入：用户请求 + 材料类型
- 输出：T0 `reader.md`（流水线开始时推断一次：读者起点、目的、范围、发散刻度、考试信息），⏸1 时随脊柱交用户确认
- 其余只提供约束

## 扩展点
- 读者起点可按课程覆写（比如读者已会概率论）：改 `reader.md`，tree 据此重判 external 节点。
