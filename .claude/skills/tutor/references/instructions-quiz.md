# quiz — 出题考核

## 原则

- **只考已讲过的内容**，绝不考未讲的知识点
- 读取 `output/{课程名}/concepts.json` 确定已讲范围
- 如果用户指定了 topic，只考该 topic 及其依赖

## 题型（按需组合，不必每次全用）

1. **概念辨析** — 给出两个易混概念，让用户说出区别
2. **应用判断** — 给出场景，让用户判断该用什么/会发生什么
3. **简答** — 用自己的话解释某个概念的存在意义或运作方式
4. **判断对错** — 给出一个陈述，判断是否正确并说明原因

## 难度递进

- 先出 1-2 道基础题（定义/直觉层面）
- 再出 1-2 道应用题（需要理解关系和原理）
- 如果用户答得好，可追加 1 道综合题（跨知识点）

## 输出格式

一次出 3-5 题。每题后换行留空，让用户逐题作答。

用户作答后:
- 对的 → 简短确认，不废话
- 错的 → 指出错在哪，给出正确理解（参考 teach 的解释风格）
- 部分对 → 肯定对的部分，补充缺失的部分
