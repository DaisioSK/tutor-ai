# 内容覆盖与保真 — Layer 0 (最高优先级)

> 这是 story / teach 写作的**内容层**规范。表达层 ([presentation.md](presentation.md) 的节奏与块类型) 和工艺层 ([writing-craft.md](writing-craft.md) 的 10 步) 都**服务于**它, 任何一条表达规则与本文件冲突时, **本文件赢**。
>
> 用户原话 (2026-09-08): "节奏和 section 的改进 80% 以上是表达方式的改进、是内容不足的补充, 绝对不是对原来硬核 lecture 内容的替换。lecture 内容必须全部覆盖, 和外部补充必须明确分开。" 以及: "我看完一个章节感觉不真实, 看得很顺, 但我不能保证我真的覆盖了全部我应该知道的内容。"
>
> 后半句是这份文件存在的理由: **覆盖必须是读者自己能核对的事实, 不是作者的保证。**

---

## 0. 四条铁律

1. **课件内容 100% 进正课**。课件每一页的每一个定义 / 公式 / 表格 / 算例 / 老师的边界警告, 都必须出现在**正课叙事或校准块 (📌 / ⚠️ / 🎯)** 里。☕ / 🎓 / 💡 是**附加**, 不得是任何课件内容的唯一载体。
2. **表达改进只增不减**。改版 / 重写 / 换风格时, 旧版覆盖的课件页和 KP, 新版一个不能少 (`verify_teach.py --baseline` 会对账)。
3. **课件内容与外部补充一眼可分**。三级标记体系 (见 §4)。没有标记的正文 = 课件内容, 读者默认信任; 所以**漏标比多标严重**。
4. **覆盖 ≠ 均摊**。100% 覆盖是**下限**, 不是排版指令。每一页都讲到, 和每一页都讲一样多, 是两件事 —— 后者等于没有重点 (见 §2)。

> 用户原话 (2026-09-14, 铁律 4 的来历): "权重不对, 不重要的地方废话连篇, 重要的地方解释不够, 让 user 读了半天抓不住重点。应该是围绕重点去讲。"

## 1. 来源标注 — 每一节都能翻回课件

### 1.1 🧭 导读条必带课件页

```markdown
> 🧭 **本节**: 中度 · 约 6 分钟 · 课件 p14-16 · 需要纸笔跟一遍
```

`课件 pN-M` 是**必填**项 (多段用逗号: `课件 p14-16, p20`), 用**物理页码** (raw txt 的 `--- Page N ---` 编号, 不是幻灯片页脚)。读者读到哪一节, 就能翻到课件哪几页对照。

### 1.2 讲末「课件对照表」(强制) — 读者侧的覆盖证明

每个 teach MD 在"本篇收束"**之前**固定一节:

```markdown
## 课件对照表

> 这张表回答"课件的每一页都讲到了吗"。左边是课件物理页, 右边是本讲位置; 豁免页给理由。对着课件 PDF 翻一遍, 哪页没讲你一眼能看出来。

| 课件页 | 该页内容 (一句话) | KP | 本讲位置 |
|---|---|---|---|
| p1 | 封面 | — | 豁免: 封面 |
| p2 | 学习目标 | — | 豁免: 路标页 |
| p3-5 | 解析模型的图示与优缺点 | KP-7.1 | §1 |
| p6 | 随机过程定义 + 两个例子 | KP-7.2 | §2 |
| p34 | 稳定性条件 λ < mµ + 两条注脚 | KP-7.16 | §10, ⚠️ |
```

规则:
- **每一页都要有一行** (连续同主题页可合并成 `p3-5`)。所有行的页并集 = 课件物理页数, 少一页脚本就 FAIL
- **豁免**只允许: 封面 / 目录 / 分节页 / 学习目标·路标页 / 总结页 (内容已在别处讲) / 致谢·参考文献 / 纯 logo / 重复动画帧。豁免必须写理由
- **KP 列**: 该页对应的 concepts.json KP id。一个 KP 跨多页就多行都写; 一页多个 KP 逗号分开
- **本讲位置**: `§N`, 可附块类型 (`§10, ⚠️` / `§11 🔍`)。**不允许**填 ☕ / 🎓 / 💡 / 📍 — 它们不能是课件内容的载体

### 1.3 KP 覆盖

文件头 `覆盖知识点:` 声明本讲 KP 范围 (如 `KP-7.1 ~ KP-7.22`, 或多段 `KP-0.1 ~ KP-0.14, KP-1.1 ~ KP-1.7`)。对照表的 KP 列必须**覆盖该范围内每一个 KP**。少一个 = 漏讲, 脚本 FAIL。

### 1.4 课件原图 — 图也是课件原文

> 为什么 (用户 2026-09-08): "有的图老师选得很好, 比我们自己画的 mermaid / 线图更好。把原图截下来放到对应章节和位置, 配上我们自己的讲解替换原有文字, 就可以媲美甚至替换原 lecture。"

`extract_figures.py` 把每页的图形区域裁成独立 PNG (`raw/figures/<stem>_p<N>_f<k>.png`, 清单在 `raw/_figures.json`)。规则:

- **原图优先于自绘**: 课件有图、且图能表达的, 正课里**嵌原图**; 自绘 (ASCII / 表格 / mermaid) 只在三种情况出现: 课件没有图、原图确实不清、需要把多页合成一张。自绘图注开头写 `自绘 ·`, 与原图一眼可分
- **哪些不截图**: 表格 (逐格抄成 Markdown 表, 可搜索、脚本能核数字)、满屏文字的页、装饰图 (人像 / 新闻配图 / logo)。`_figures.json` 的 `looks_like_table` 与 `text_inside` 帮你判断, 最终看图定
- **图注格式固定**, 独占一段, 页码必填:
  ```markdown
  ![课件 p20 · 概率路由的开放网络: λ1 进 server1, 完成后按 p12 / p13 / p1 分流](../raw/figures/lectures_L3-IntroQueueing_p20_f1.png)
  ```
  图注 = `课件 pN · 一句话说图在讲什么`。图内英文标签不翻译, 讲解段里对照解释
- **图必须紧跟讲解**: 图前一段引入它, 图后一段逐元素讲它 (老师放这张图时嘴上说的话, 由我们的讲解补上)。只贴图不讲 = 把课件原样搬来, 不是教学
- **图是正课载体**: 嵌原图算覆盖该页 (对照表"本讲位置"可写 `§5 🖼`); 但图里的公式 / 数值仍要在正文出现一次, 不能"看图自取"
- 相同图重复出现的页 (动画帧 / 复习页) 只嵌一次, 对照表其余页标 `同 pN 图`

## 2. 分量 — 篇幅按重要度分配

### 2.0 每节的教学目标 (post status) — 先定目标, 再定篇幅

> 用户原话 (2026-09-15): "每个小节都要有教学目标 (看完本小节 user 应该懂到什么程度, 会算什么计算),
> 所有小节的目标总和必须完全覆盖一个课程的总目标 …… 简单来讲, 用教学目标的方式来给不同的小节内容「加权」。"

分量档位 (§2.2) 回答"这节占多少篇幅", 但篇幅不是目的 —— 目的是读者读完这一节真的**能做到某件事**。
所以每个 § 收尾必须有一个 **post status 块**, 用可检验的动作写出这节的教学目标:

```markdown
> ✅ **学完这节**: 给 λ、μ、m 能算 ρ 并判稳定。
```

写法要求 —— **一行, 越短越好** (用户 2026-09-15: "可以不用打印到课件, 或者用最简短的表述"):

- **一节一行, ≤ 40 字**。目标是作者的加权尺, 不是给读者的第二份小结; 写成两三行就成了复述, 立刻超支
- **动作可检验**: "会算 / 能判断 / 能写出 / 能推出 / 能说出为什么" —— 不写"理解 / 熟悉 / 掌握"这类没法验的词
- **会算什么就写算什么**: 带公式的节写成"给 {输入} 能算 {输出}", 不重复公式本身 (公式在正文和 📌 里已经有了)
- **多个目标用顿号并成一句**, 并不出来说明这节塞了两节的量, 拆节
- **背景 § 也要有**, 更轻: "能认出这张图在说什么" 一句即可
- 位置固定在该 § 的最后一个块, 读者读完立刻能自查

**要不要印进 PDF**: 默认印 —— 编译器把它压成一行小字、不挂标签 chip, 一节只多一行。
版面吃紧或读者不需要自查时, 编译加 `--no-goals` 完全不打印; MD 里的块**任何情况下都保留** (门禁和加权依据靠它)。

**目标之和 = 总目标 (硬约束)**

讲首「必须带走的 N 条」(§2.1) 是这一讲的总目标。**每一条都要能指到承担它的 §** —— 在大纲里逐条标落点
(`1. {…} (§7, §9)`)。指不到 → 这一讲缺了一节, 不是"让读者自己悟"。反向也成立: 某个 § 的目标既不服务于任何一条
N 条、也不为后面的节做地基 → 这节是装饰, 砍掉或压成背景。

**这就是"加权"的判据**: 篇幅不按课件页数平摊, 按"读者从现在的认知走到这条目标还差多少"给 ——
差得多 (要推公式、要过手算、要破直觉) 就多写; 目标只是"认个脸"就一段话。

### 2.0.1 验收: 顺读自足测试 (accumulative read-through)

交付前从 §1 顺着读到最后一节, **每到一节结尾停下**, 只拿「这一节 + 前面所有节已经给过的东西」
(不许回翻课件、不许查外部、不许拿"这是常识"搪塞), 问一句: 一个小白到得了这节的 ✅ 目标吗?

- **到不了 → 加权多说。** 缺的通常是例子、中间步骤、或"为什么是这样"的交代。典型手感:
  **像剧情马上进高潮却被夹断**; 或**像看侦探剧, 推理站不住脚, 关键处根本没交代**。哪一步让你"嗯?"就补哪一步。
- **到得了, 但同一件事已经是第三遍 → 精简。** 删重复的定位段落和二次复述, 不是删例子。
- 补出来的字数**优先从重复段和背景 § 挪**, 而不是让整篇变长 —— 加权是再分配, 不是通胀。

这一测试是门禁的一部分 (instructions-story.md 门 0), 脚本只能验目标块在不在, 够不够到得了必须人读一遍。

### 2.1 先定"必须带走的 N 条", 再分配篇幅

动笔前, 对这一讲回答一个问题: **读者读完只记住 3-5 件事, 该是哪几件?**
判据按序: ① `concepts.json` 的 `exam_high_points`; ② 课件自己的强调程度 (有公式汇总页 / 有数值算例 / 反复出现 / 老师专门标星); ③ 它是不是后面几讲的地基。

这 N 条写进讲首的大纲块 (§2.3), 并**决定全讲的篇幅分配**。写完回头对一遍: 篇幅最长的几节, 是不是就是这 N 条?不是 → 权重错了, 不是"再补一点", 是**把长错的地方砍掉**。

### 2.2 三档分量, 每个 § 必须标一档

分量 (这节多重要) 和负载 (这节多难读) 是两件事, **导读条两个都写**, 分量在前:

```markdown
> 🧭 **本节**: 🎯核心 · 重度 · 约 12 分钟 · 课件 p18-21 · 需要纸笔跟一遍
> 🧭 **本节**: 背景 · 轻度 · 约 3 分钟 · 课件 p8
```

| 分量 | 是什么 | 篇幅 | 允许的块 |
|---|---|---|---|
| **🎯核心** | 必须带走的 N 条, 及其直接推导 | 全讲篇幅的 **≥ 55%** 落在这里; 单节可以很长 | 全部块类型; 📏 三档只在这里开 |
| **常规** | 支撑核心的机制、术语、分类 | ~30% | 正课 + 按需 📌 / ⚠️ / 🎯 |
| **背景** | 动机页、路标页、时间线、一次性的对照表、"知道有这回事"的清单 | ≤ 15%, **单节 ≤ 800 字** | 正课 + 最多一个校准块。**不开 📏, 不硬配 💡 / ☕** |

**背景 § 的压缩规则** (照着做, 这是上一版最大的字数泄漏点):

- 课件一页只给了一张对照表 / 一份清单 → **正文一句话说清它要说明什么 + 表格逐格照抄**, 不要再逐行复述表里已有的内容
- 📌 定义**不得复述已经在正文出现过的表格或公式全文** —— 它是速查卡, 不是备份。超过两行就说明写成备份了
- 不为了凑"质地下限"硬配 💡 / ☕ / 📏。**质地下限对背景 § 不适用** (presentation.md Layer B 规则 2)
- 一节写完自检: 删掉这一节, 读者会不会答不出核心的那 N 条?不会 → 它就该是背景, 砍到 800 字以内

### 2.3 讲首「本讲大纲」(强制)

紧跟在读法指南之后、`## 开篇` 之前, 每讲必须有一节 `## 本讲大纲`, 四件东西:

1. **必须带走的 N 条** —— `> 🎯 **这一讲必须带走的 N 条**` 块, 一条一行
2. **一张 mermaid 流程图** —— 认知段落 (`subgraph`) 里排着若干 §, 节点按分量上色。这是读者的地图: 讲了哪些、哪几个是重点、现在读到哪一段
3. **索引表** —— `| 段 | § | 分量 | 课件页 |`, 每个 § 一行, § 号写成指向该节的链接
4. **一句"这一讲不展开什么"** —— 豁免的课件页 + 一句理由 (逐页理由仍在讲末对照表)

mermaid 只用这个子集 (PDF 编译器 `render_mermaid` 认得, 无需 JS 和外部服务; IDE / GitHub 里是标准 mermaid):

```markdown
​```mermaid
flowchart TD
  subgraph A["① 把话说准 · §1-§4"]
    A2["§2 六个术语"]:::core
    A3["§3 时间尺度"]:::bg
  end
  subgraph B["② 从哪下手 · §5-§8"]
    B7["§7 USE / RED"]:::core
  end
  A -->|术语就位| B
  classDef core fill:#fdecea,stroke:#c62828
  classDef bg fill:#f3f5f7,stroke:#d8dde2
​```
```

节点类名固定三个: `core` (🎯核心) / 不标 (常规) / `bg` (背景); 课件里存在但本讲不展开的用 `skip`。**一个 § 一个节点, 不漏不并**。

### 2.4 大纲要管到读者读完为止

> 用户原话 (2026-09-14): "大纲是要的, 是读的过程中始终让 user 明白我在哪里, 我在看什么部分。"

大纲只在讲首出现一次是不够的 —— 读到第 12 节时读者早忘了自己在哪一段。所以编译器**从大纲派生出一条阅读位置面包屑**:
每个 § 标题前自动盖一行 `{段名} · §{N}/{总数} {节短名}`, 并把它设成 PDF 的 **running header** ——
之后每一页的页眉都写着当前所在的段与节, 翻到哪儿都知道自己在哪。

面包屑**不用作者另写**, 它从大纲的 mermaid 里取, 所以永远和大纲一致。代价是两条命名约束:

| 元素 | 写法 | 约束 |
|---|---|---|
| `subgraph` 的 label | `"① 把话说准 · §1-§4"` | `·` 左边是段名, **≤ 8 字**; 右边是 § 范围 |
| 节点的 label | `"§4 两副面孔与饱和"` | 必须 `§N ` 开头; 后面是节短名, **≤ 12 字** |

节短名不是章节全名 —— 全名带英文副标题, 塞进页眉会截断。取标题里最能认出这一节的那几个字。

## 3. 正课承载 — 什么必须在正课里

课件里的这些东西, 必须出现在**正课叙事或 📌 / ⚠️ / 🎯 校准块**:

| 课件元素 | 落点 | 不合格的落点 |
|---|---|---|
| 每个定义 (老师的措辞, 见 writing-craft "3 抽") | 正课 Step 2 + 📌 | 只在 💡 里用类比带过 |
| 每个公式 | 正课 Step 5 (思路→公式→拆解) | 只在 🎓 里"往上一层"却不给原式 |
| 每张表格 | 正课, 逐格照抄数值 | 只在 ☕ 里用画面代替 |
| 每个算例 | 正课, 走完算式 | 改成虚构演示数 (虚构数只能**另加**, 不能**替代**) |
| 老师强调的边界 / 陷阱 | ⚠️ 或正课 | 只在 🎓 透镜 3 里当"从业者判断" |
| 老师给的例子 | 正课 或 🔍 的**真实场景段** | 只在 🔍 的**入门虚构段** (虚构段是自编的, 不算覆盖) |

违规判定很简单: **把所有 ☕ / 🎓 / 💡 / 📍 块删掉, 剩下的正文是否还完整覆盖课件?** 是 → 合格; 否 → 表达层在替换内容层, 违规。

## 4. 外部补充 — 三级标记, 一眼可分

| 级别 | 什么时候用 | 标记 | 读者看到的信号 |
|---|---|---|---|
| 行内 | 正课句子里夹一个课件外的事实 / 术语 / 数字 | 句边 ⚡ | 这半句是补的 |
| 整块 | 换气 / 师门心法 / 类比 | ☕ 🎓 💡 块 (块类型即标记) | 这整块是补的, 累了 / 考前可跳 |
| 整节 | 发散概念 (L1 / L2 / L3) | 标题 ⚡ + 节首 📍 说明 | 这一节不在课件里 |

- **外部补充总量** (☕ + 🎓 + 💡 + 📍 块字符 + 含 ⚡ 的行) 建议 **≤ 全文 25%**。超过说明表达层在挤内容层 — 回头看是不是正课写薄了, 而不是把补充删掉凑数。
- 🎓 必须挂在课件的某个结论上 (writing-craft Step 8 三判据); ☕ 必须 link back 到概念。它们**围着课件内容转**, 不另起话题。
- 补充块里同样**禁止编造**年份 / 人名引语 / 具体数字 (见 §5)。

## 5. 保真清单 — 不编造

> 为什么有这段: 一次红队审查实锤了以下每一种失守——伪造出处 (把 Illustrated Transformer 例句说成"老师课件里反复出现")、编造时间线连引语 (GPT-2/GPT-3 Pre-LN)、替换课件真实名单 (生产公司表)、篡改决策表阈值 (<8 GPUs → <16 GPU)、伪精确数字 (24576 CUDA core / 快 7% / 利润率 30-50%)。风格再好, 这些进了备考材料就是把假数字送进答卷。

- [ ] **课件外必标 ⚡**: 任何在 raw/*.txt 中 grep 不到的专有名词 / 具体数字 / 公司名 / 时间线 / 引语, 要么删掉, 要么句边带 ⚡。默认怀疑自己的先验。例外: ☕ / 🎓 / 💡 整块天然是课件外, 块类型即标记, 块内不必逐句 ⚡ — 但块内同样禁止编造。
- [ ] **表格数值禁改写**: 课件里的决策表 / 结果表 / 对比表, 数值和行项**逐格照抄** (表述可以口语化, 数字和阈值不能动, 行不能删也不能加 — 要加就单独标 ⚡ 另起)。
- [ ] **禁伪精确**: 课件说 "thousands of threads" 就不能写成 "24576 个"; 课件说 "cost is lower" 就不能写成 "省 40-70%"。没有来源的数字用定性表述。
- [ ] **出处不伪造**: 不得把课件外的例子 / 引语说成"老师讲的 / 课件里的"。示例演算的假想数字要声明"编个数演示"。
- [ ] **引用不空头**: 写 "L4 会讲 / Arc N 见" 前先确认那里真的讲了 (或计划里明确会讲)。
- [ ] **推导算术展示算式**: 由课件数值做的衍生算术 (如 99.999% → 5.3 min/年) 是合法的, 但必须**显式给出算式** — 展示了推导过程即视同已溯源; 只报结果数则按伪精确处理。
- [ ] **课件笔误照抄 + 注**: 课件印错的 (如 686 应为 68.6), 照抄原值 + ⚠️ 给出算式说明"疑为笔误", 不静默改。
- [ ] **抽验回查**: 每讲写完抽 5 个具体数字 / 专有名词回 raw/ grep。验不到又没标 ⚡ 的, 按第一条处理。三类豁免: 已声明的虚构演示数、带算式的推导数、⚡ 已标。

## 6. 验证 — 用脚本, 不用自觉

写完每个 teach MD, **交付前必跑**:

```bash
<python> ${CLAUDE_SKILL_DIR}/scripts/verify_teach.py output/{课程名} output/{课程名}/teach/{N}-xxx.md [--baseline 旧版.md]
```

脚本检查 (任一 FAIL 不得交付):

| 检查 | 判据 |
|---|---|
| KP 覆盖 | 文件头声明范围内的每个 KP 都出现在对照表 KP 列 |
| 页覆盖 | 对照表页并集 (含豁免) = 课件物理页数; 未覆盖页逐页列出; 豁免行必须有理由词 |
| 位置合法 | 对照表"本讲位置"不含 ☕ / 🎓 / 💡 / 📍 |
| 导读条 | 每个 `## §N` 下第一行是 🧭, 且含 `课件 p..`、`约 N 分钟`、**分量 (🎯核心 / 常规 / 背景)** |
| 分钟一致 | 各 § 分钟之和 = 文件头 `预计阅读` |
| 本讲大纲 | 有 `## 本讲大纲` 一节, 含"必须带走的 N 条" + mermaid 图 + 每个 § 一行的索引表 (§2.3) |
| 面包屑可用 | 大纲每个节点写成 `§N 短名` 且短名 ≤ 12 字; 每个 subgraph label 带 `·` 分段名 (§2.4) |
| 教学目标 | 每个 § 末尾有 `✅ 学完这节` 块, 且用可检验动作 (会算/能判断/能写出…) (§2.0) |
| 目标落点 | 大纲「必须带走的 N 条」每条都标了承担它的 § (§2.0) |
| 权重 | 背景 § 不得长于核心 § 的中位数; 核心 § 篇幅合计 ≥ 45% (§2.2) |
| 预算 | ☕ ≤ 8% 字符、🎓 ≤ 15%、外部补充总量 ≤ 25% (WARN) |
| 残留 | 无 🧠、无元叙事禁词 |
| 只增不减 | `--baseline`: 旧版对照表 (或页码引用) 里的页和 KP, 新版都有 |
| 课件原图 | 每个 `![...](...)` 文件存在; 图注含 `课件 pN` 或以 `自绘` 开头; 图注页码在对照表内; 图前后有正文段 (不许图贴图、图贴标题); `_figures.json` 有图而正文零嵌图 → WARN |

脚本能验的是**结构** — 页有没有被认领、KP 有没有被对上、目标块在不在。**目标够不够得到, 脚本验不了** — 那是 §2.0.1 的顺读自足测试, 必须人顺着读一遍。每个公式是否照老师写法、每张表是否逐格照抄, 仍靠 §4 的抽验回查。**两者缺一不可**: 脚本防整块蒸发, 抽验防细节走样。
