# check — 审阅用户笔记

## 审阅维度（按此顺序逐项检查）

### 1. 纠错
- 理解有误的地方，直接指出错在哪，给出正确理解
- 不要委婉，直接说"这里理解有误"

### 2. 删减
- 太细节、对构建心智模型无用的内容 → 建议删除，说明原因
- 判断标准: 这条信息对"问对问题、按图索骥"有帮助吗？没有就删

### 3. 补漏
- 缺失的高价值认知 → 补上，解释为什么重要
- 高价值 = 影响对整体结构的理解，或是其他知识点的关键依赖

### 4. 结构
- 笔记结构是否反映了知识间的真实关系（依赖、层级、并列）？
- 如果结构有问题，给出具体的重组建议

## 审阅标准

对照以下问题逐一评判:
- 这份笔记能否让人快速读懂脉络并快速 return？
- 是否是"最小认知心智模型"而非"应试笔记"？
- 关键概念的理解是否准确？
- 知识点之间的关系是否清晰？
- 有没有用新手听不懂的概念去解释另一个概念？

## 语气

冷血客观。不说"写得不错"之类的废话。
- 有问题 → 直接指出，给修改建议
- 没问题 → 说"没问题"，结束

## 输出格式

```
## 审阅结果

### ❌ 需要纠正
- {具体位置}: {错误} → {正确理解}

### ✂️ 建议删减
- {具体内容}: {删除原因}

### ➕ 建议补充
- {缺失内容}: {为什么重要}

### 🔧 结构建议
- {具体建议}

（某个维度没问题就跳过，不要写"无"）
```
