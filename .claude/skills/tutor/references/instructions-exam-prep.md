# exam-prep — 考试题集解析 + 核心认知讲义

## 触发

`/tutor {课程名} exam-prep`

## Phase 1: 识别重要考点

从以下来源综合判断重要程度:
1. **往年考题** — 直接出过的 = 最高优先级
2. **课件重复** — 同一概念在多个 Lecture 出现 = 高优先级
3. **课件强调** — "Key!", "Important!", 加粗/高亮的内容
4. **concepts.json** 中 `exam_high_freq` 标签

## Phase 2: 整理题集

读取 `courses/{课程名}/` 下的考题 PDF (已提取为 txt)。

对每道题，按以下格式输出:

```markdown
---
### 题 {N}

**原题**: {英文原题}
**翻译**: {中文翻译}

**正确答案**: ({字母})

**拆解思路**:
1. 这题在问什么 → {一句话}
2. 关键判断 → {为什么选这个}
3. 排除法 → {其他选项错在哪}

**选项分析**:
- (a) {内容} → ❌ {错因}
- (b) {内容} → ❌ {错因}
- (c) {内容} → ✅ {对因}
- (d) {内容} → ❌ {错因}
- (e) {内容} → ❌ {错因}

**考点关键词**: {1-3个}

**核心认知** (做对这题需要懂的):
{2-3句话，把做对这题需要的知识讲清楚}
```

对于简答题:
```markdown
---
### 题 {N} (简答)

**原题**: {英文}
**翻译**: {中文}

**标准答案**: {答案}

**答题思路**: {怎么想到这个答案的}

**考点**: {关键词}
**核心认知**: {2-3句话}
```

## Phase 3: 总结

所有题做完后，产出三个东西:

### 3.1 考察维度分析
```markdown
## 考察维度
| 维度 | 题号 | 占比 |
|------|------|------|
| 服务模型选型 | Q1,Q4,Q12... | X% |
| 虚拟化/容器 | Q5,Q6... | X% |
| ... | | |
```

### 3.2 核心认知讲义
```markdown
## 核心认知讲义
> 看完这份讲义，保证做对题集中所有题目以及同类题

### 认知 1: {标题}
{精炼解释，覆盖相关所有题目的考点}

### 认知 2: ...
```

### 3.3 全局知识图谱
```markdown
## 全局知识图谱
[ASCII 图: 所有考点的关系网络，强调联系，忽略细节]
```

## Phase 4: 回填 teach/ 差距

逐题检查: 这道题考的知识点在 `teach/` 里讲到了吗？

- **已覆盖** → 跳过
- **未覆盖或覆盖不够** → 补入对应 Arc 的 § 章节，标注考卷来源（如"Sem1 Q3 考过"）
- 补完后重新运行 `compile_story_pdf.py` 更新 PDF

这一步的意义: teach/ 是用户的主学习材料。如果考试考了但 teach/ 没讲，用户考场上翻 PDF 也找不到。**考卷是 teach/ 内容完整性的最终检验。**

## Phase 5: 生成考试关键词索引（如果用户说"考试用"/"open book"）

如果用户说需要用于考试 / open book:

1. 生成 `output/{课程名}/teach/exam-keyword-index.md` — 关键词 → Arc/§ 速查表
2. 格式: 按板块分表，每行 = 英文关键词 | 跳转位置 | 一句话提示
3. `compile_story_pdf.py` 会自动把它编入 PDF 尾部

## 输出文件

- `output/{课程名}/exam-prep/questions-{考卷名}.md` — 每套卷子的详细解析
- `output/{课程名}/exam-prep/core-knowledge.md` — 核心认知讲义
- `output/{课程名}/exam-prep/summary.md` — 考察维度 + 知识图谱
- `output/{课程名}/teach/exam-keyword-index.md` — 关键词速查索引（如需要）
