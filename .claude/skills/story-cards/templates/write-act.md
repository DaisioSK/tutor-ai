# write-act — 写一幕的故事卡片（各幕并行）

> 调度者：每幕一份，填好 `{…}` 整份发出。大幕（> 50 节）按集拆成两份并行，文件名 `act03a` / `act03b`。

根目录 R = `{R}`，书 B = `{B}`，速查册 C = `{C 或"无"}`，产物目录 O = `{O}`，skill S = `R/.claude/skills/story-cards`。跑 Python：`{PY}`。用 Write/Edit 写文件（经 shell 写文本会吞反斜杠）。

## 你写什么
`O/parts/act{NN}.md`：第 {X} 幕（卷 {X}，第 {a}–{b} 章，集 {i}–{j}）。只写这一份文件。

## 先读（只读这些）
1. `S/SPEC.md`：**全部规则，逐条照做**。
2. `O/world.md`：意象对照表（意象一律照它，不自创）与集表（你这几集的标题、开场麻烦、收尾钩子）。
3. 书里你这几章：每节 `## §N.M` 按需读（grep 定位）。重点抽取：核心结论或公式、前提、`> ⚠️` 陷阱、边界、例题的数；🧠 心智卡的"一句话"（故事结论要和它一致）。
4. 讲者脉络 `{LF}/L*.md` 里你这几章对应的讲：每步的例子、老师的直觉原话、"为什么转到这里"。故事优先演老师的推进、用老师的例子（SPEC 第 10 条）；技术要点里老师的原话可以保留英文作锚。
5. 往年题落点：`B/99-back.md`「附录 A 往年题 → 本书各节」里属于你这几章的行（决定哪些行标 🎯）。速查册 C 若有，同一个 § 的知识点可以对照，取其中的 ⚠️ 与条件。

## 写法
- 幕标题、幕首一句；每集"开场 → 五列表 → 收尾"，开场和收尾照集表的麻烦和钩子写。
- 一节一行；你这几章的每个 `## §N.M` 都要有一行。
- 技术要点第一遍就写全：核心与关键公式（该节公式卡、书尾公式墙）、🎯 考过的知识（用附录 A 往年题、速查册 🎯 找出，写知识本身、不写题号）、前提、⚠️、边界、符号（SPEC 第 11 条）；一节装不下就拆成（1/3）（2/3）几行。和故事的联系里，最重要的前提用 ∵∴ 推出来（SPEC 第 12 条）。
- 技术要点开头两行：`💡 洞察`（书里理解向标题答出来）、`↩ 承接`（从前面哪节的哪个结果长出来）。先跑 `python3 S/scripts/links.py <full-learn 工作区> {a} {b}` 拿每节的依赖、回指、开场过渡（SPEC 第 11 条）。
- 节名：有标准名的节写 `§N.M「标准名」`，书里的理解向标题挪进技术要点第一行（SPEC 第 9 条）。
- 推导：由前面推出来的公式附 `推导：` 2–5 步；定义标（定义），书里不推的标（不推，直接用）（SPEC 第 11 条）。
- 前置准备节（数学或概念工具）技术要点先答三问：原来解决什么问题 / 核心思想 / 为什么正好用得上（SPEC 第 11a 条）。
- 计算样例：🧮 行和有公式的行各一道口算题，题 → 公式 → 代入 → 结果（SPEC 第 12a 条），数自己验算。
- 不超前引用（SPEC 第 5 条）：只用第 {b} 章及以前讲过的东西；拿不准某个概念书里第几章才讲，grep 书确认。
- 数、公式只取自书。

## 自查
`python3 S/scripts/concepts.py O/parts/act{NN}.md`：`missing` 与 `no_en` 都为 0（故事里注过的概念，技术要点都提到、首次出现带英文）；再人工扫一遍技术要点格，没解释的术语补上。
`python3 S/scripts/check.py O/parts/act{NN}.md B --quiet`。这一步只看你这一份：coverage 会报其他幕的节"缺"，忽略，只确认你这几章的节一个不缺。另外 columns、where、symbols、calc 无 FAIL，bullets 无 WARN。
超前引用：其他幕交回后调度者会跑 `forward.py` 全表核对；你先自己扫一遍"第X卷 / §N.M / 后面会讲"这类字样。
